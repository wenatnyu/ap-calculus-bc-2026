AP Calculus BC · Topic 5.1

Using the Mean Value Theorem

使用中值定理

If f is continuous on [a,b] and differentiable on (a,b), then
f′(c)=f(b)−f(a)b−a for some c∈(a,b).

At some interior point, an instantaneous rate matches the average rate.某个区间内部点的瞬时变化率等于区间平均变化率。

State the MVT Precisely

Interior value

Geometric meaning

Secant Slope Meets Tangent Slope

割线斜率等于某条切线斜率

Average rate

msec=f(b)−f(a)b−a

Uses two endpoints.由两个端点决定。

Instantaneous rate

mtan=f′(c)

Uses one interior input.在一个内部点取得。

The MVT guarantees parallel secant and tangent lines when both hypotheses hold.满足条件时，存在与割线平行的切线。

Geometry explains the equation.04

可画一条割线和一条平行切线；强调 MVT 不要求找出图上唯一的一条。

Do not mix the theorems

MVT and IVT Do Different Jobs

中值定理与介值定理的结论不同

TheoremWhat must be continuous?What is guaranteed?
Intermediate Value Theoremf on [a,b]A function value f(c)=L
Mean Value Theoremf on [a,b], plus differentiability insideA derivative value f′(c)=msec

Word clue: “attains a height” points to IVT; “attains a rate” points to MVT.函数值用 IVT，导数值用 MVT。

Find the Guaranteed Value

先算平均斜率，再解导数方程

f(x)=−x²+3x+10 on [2,6]

f(6)−f(2)6−2=−5

f′(x)=−2x+3

−2c+3=−5

c=4

4∈(2,6), so it is valid.

Four-step method

A Reliable MVT Workflow

固定四步，避免只解方程不验条件

1

Check continuity on [a,b].

2

Check differentiability on (a,b).

3

Compute the secant slope.

4

Solve f′(c)=msec and keep only interior values.

A correct algebraic value is not an MVT conclusion unless the hypotheses are stated.考试论证必须写条件。

A Radical Function on [1,3]

先确认根号内在区间上为正

f(x)=√(15−5x)

msec=0−√102=−√10/2

f′(x)=−52√(15−5x)

f′(c)=−√10/2 ⟹ c=5/2

The derivative need not exist at an endpoint; MVT asks for differentiability only on (1,3).端点只要求连续。

An Exponential Interval

先保留精确值，再判断是否在区间内

msec=2−1ln 2=1/ln 2

ec=1/ln 2

c=ln(1/ln 2)

Interpret the conclusion

Existence Is Not Uniqueness

定理保证存在，不保证唯一

Possible outcome

One interior solution to f′(c)=msec.

Also possible

Several interior solutions, all valid.

If the equation has no interior solution, at least one hypothesis must have failed—or the algebra is wrong.满足条件却找不到 c，先检查计算。

“There exists” means at least one.12

可举 sin x 在较长区间上同一斜率出现多次的情形，只强调“至少一个”，不展开后续内容。

Exam check · Conditions

Can the MVT Be Applied?

先判断条件，再谈 c

f(x)=|x| on [−1,1]

  • A.Yes; c=0
  • B.Yes; every c works
  • C.No; f is not continuous
  • D.No; f is not differentiable at 0
D. The average slope is 0, but f′(0) does not exist. The differentiability hypothesis fails.仅算出平均斜率不代表可以使用 MVT。
Hypotheses control the theorem.14

让学生指出失败点在开区间内部，因此不能套用 MVT；连续性本身没有失败。

Exit ticket · Full MVT statement

Find the Interior Value

完整写出条件、方程与答案

f(x)=x²+1 on [0,2]

Find every c guaranteed by the MVT.

c=1. A polynomial is continuous on [0,2] and differentiable on (0,2). The average slope is [5−1]/2=2. Since f′(c)=2c, 2c=2 gives c=1.先写条件，再算平均斜率。
