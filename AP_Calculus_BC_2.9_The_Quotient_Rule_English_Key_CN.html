The Quotient Rule

商法则

If h(x)=f(x)/g(x),

h′(x)=f′g−fg′g2

with g(x)≠0

Order matters in the numerator, and the entire denominator is squared.分子减法顺序固定，分母整体平方。

Low d-high minus high d-low · Low squared

先约定 high=f、low=g，然后用固定口令读公式。强调原分母不能为零。

Core formula

The Quotient Rule

四个位置，一个固定结构

h=fg

h′=f′g−fg′g2

  1. Differentiate the numerator.
  2. Keep the denominator.
  3. Subtract numerator times denominator derivative.
  4. Divide by denominator squared.

Do not reverse the subtraction. Reversing it changes the sign of the derivative.分子两项颠倒会使答案整体变号。

Parentheses protect the structure.03

要求学生先写完整结构再代函数。若用“low d-high”口令，也要确保最终与 f′g−fg′ 一致。

Check the Rule by Simplifying

能先化简时，用结果检查商法则

q(x)=x2/x=x

q′(x)=1

for x≠0

Quotient rule

q′=2x·x−x2·1x2

=1

The derivative agrees on the original domain. The excluded input x=0 stays excluded.化简不会补回原函数没有定义的点。

Simplifying can verify both structure and sign.04

Table Strategy

表格商法则的固定流程

1

Write (f′g−fg′)/g².先写结构。

2

Find one requested row.锁定输入。

3

Read f,f′,g,g′.四列分清。

4

Use parentheses for negatives.负数加括号。

The denominator is [g(a)]², not g′(a)².分母平方用函数值，不是导数值。

Read the table only after the formula is ready.11

Protect the Order

商法则求导并写切线

q(x)=x2+1x+1

Find q′(x), then write the tangent line at x=0.

Answer: q′(x)=[2x(x+1)−(x²+1)]/(x+1)²=(x²+2x−1)/(x+1)². At 0, the point is (0,1) and slope is −1, so y=1−x.点来自 q(0)，斜率来自 q′(0)。
