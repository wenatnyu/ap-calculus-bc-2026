Definition · The limit comes first

What Makes a Discontinuity Removable?

可去的前提：有限双侧极限已经存在

At x=c, let limx→c f(x)=L, where L is finite.

The discontinuity is removable if f(c) is undefined or f(c)≠L.

Repair: define or redefine f(c)=L.把点值改成极限值。
Not enough: if the two-sided limit is DNE or infinite, one point value cannot help.双侧极限不存在或无穷时，改一个点无效。
Nearby behavior must already agree.03

先说必要条件：finite two-sided limit exists。之后才讨论点值是否缺失或错误。

Limit versus point value

Why One Value Can Repair a Hole

极限看附近，连续性还要求点值匹配

01

Approach c

Use values with x≠c.

先看点附近。
02

Find L

Both sides approach the same finite number.

左右趋近同一有限值。
03

Check f(c)

It may be missing or incorrect.

点值可能缺失或错误。
04

Match it

Set f(c)=L.

令点值等于极限。

Changing f(c) does not change the limit. It changes only whether the function is continuous at c.改单点不改变极限，只改变该点是否连续。

Limit first · Point value second04

让学生口头区分：limit 是附近趋势，continuity 还包括点值。

Procedure · Keep the original restriction

Rational-Function Workflow

有理函数补洞流程

01

Factor

Factor numerator and denominator completely.

完全因式分解。
02

Record exclusions

Find zeros of the original denominator.

记录原分母零点。
03

Cancel nearby

Cancel common factors only for x≠c.

约分后仍保留限制。
04

Evaluate L

Substitute into the simplified nearby rule.

代入化简后的附近规律。

Do not erase the hole. Algebraic cancellation creates an equivalent rule nearby, not a new value at the excluded input.约分不会自动给原函数补上点值。

Find the Hole, Including Its y-Value

空洞要写出 x 坐标和 y 坐标

f(x)=x²−1x−1

=(x−1)(x+1)x−1=x+1,   x≠1

limx→1f(x)=2

Coordinates

x-coordinate: 1, from the canceled factor.

y-coordinate: 2, from the limit.

Hole: (1,2)空洞坐标为 (1,2)。

The simplified rule supplies the approached height.06

Worked example · Define the missing value

Build a Continuous Extension

用极限定义缺失点值

f(x)=x²+6x+8x+4,   x≠−4

=(x+4)(x+2)x+4=x+2

limx→−4f(x)=−2

Define f(−4)=−2.

Result: the extended function is continuous at x=−4.补成 −2 后，该点连续。

Required value: −2. The factor cancels nearby, but the original restriction remains until we explicitly define the missing value.
Official packet notes, Question 207

Mixed classification · Cancel carefully

One Formula Can Have a Hole and an Asymptote

同一函数可以同时有空洞和竖直渐近线

r(x)=x²−4x²−x−2

=(x−2)(x+2)(x−2)(x+1)=x+2x+1, x≠2,−1

Canceled zero: x=2 → hole.

Surviving zero: x=−1 → vertical asymptote.

Hole height: (2+2)/(2+1)=4/3.

Hole: (2,4/3)
VA: x=−1

Cancellation classifies denominator zeros.11

这是连接下一节的桥梁。先分类每个原分母零点：约掉则 hole，保留则可能 VA。

Error analysis · Precise language

Three Common Errors

三个常见错误

“Cancel means defined.”

False.

The original input is still excluded until a value is explicitly assigned.

约分不会自动补点。

“Any DNE is removable.”

False.

A removable discontinuity needs one finite two-sided limit.

可去间断必须有有限双侧极限。

“Use f(c) to find the limit.”

False.

Find the nearby limit first; then choose the point value.

先求极限，再定点值。
State the domain restriction every time.13

每个错误请学生用一句英文纠正。特别检查他们是否把“约分后的式子”误当成原函数在洞处已有定义。

Exit ticket · Decide and justify

Can One Point Fix It?

判断能否只改一个点使其连续

A

lim x→4− f(x)=7
lim x→4+ f(x)=7
f(4)=−2

Can we repair it?

B

lim x→4− g(x)=7
lim x→4+ g(x)=−2
g(4) undefined

Can we repair it?

A: yes - redefine f(4)=7. B: no. Its one-sided limits disagree, so the two-sided limit does not exist.A 可补成 7；B 是跳跃，改单点无效。
Finite two-sided limit → match the point value
Next: infinite limits and vertical asymptotes15

收尾要求完整句子：A removable because the finite two-sided limit exists; B nonremovable because the sides disagree.
