Using the Candidates Test to Determine Absolute Extrema

用候选检验法判断绝对极值

On a closed interval:

evaluate f at every interior critical number and both endpoints.

Absolute extrema come from comparing actual function values.绝对极值要比较所有候选点的函数值。

The theorem behind the method

EVT Gives the Guarantee

闭区间连续保证绝对最大值和最小值都能取得

If f is continuous on [a,b], the Extreme Value Theorem guarantees both absolute extrema.

Inside the interval

An extremum can occur where f′=0 or f′ does not exist.

At the boundary

An absolute extremum can occur at a or b.

That is why endpoints must be evaluated even though they are not interior critical numbers.端点是独立候选类别。

Interior candidates + boundary candidates03

把 5.2 的 EVT 与本节算法连接起来。端点不能因“导数没有定义”而被漏掉。

Reliable procedure

The Candidates Test

候选检验法四步流程

1

Find f′.

2

Find every interior critical number.

3

Evaluate f at critical numbers and endpoints.

4

Choose the least and greatest values.

Use the original function—not the derivative—in the comparison table.比较的是 f(c)，不是 f′(c)。

Find inputs · Evaluate outputs · Compare04

要求学生每次画两列表：candidate x 与 f(x)。这能直接暴露把导数值当极值的错误。

Official test prep · EVT failure

A Supremum Need Not Be Attained

不连续时，最高上界可能不是最大值

f(x)={ x², 0≤x<1;   0, 1≤x≤2 }

Absolute minimum

0 is attained, for example at x=0 and every x∈[1,2].

Absolute maximum

There is none: values approach 1 as x→1⁻, but f(1)=0.

The supremum is 1, but 1 is not a function value.“接近”不等于“取得”。

Official answer: the minimum exists; the maximum does not.11

官方题答案对应 B。EVT 不适用因为 x=1 不连续；强调 absolute maximum 必须 attained。

Candidates Test 的标准形式针对闭区间

DomainEndpoint candidates?Guaranteed extrema?

Exam check · Complete candidate list

Which Inputs Must Be Evaluated?

端点与内部临界数都不能漏

A function f is continuous on [−3,4]. Its only interior critical numbers are −1 and 2. Which list is sufficient for the Candidates Test?

  • A.−1,2
  • B.−3,4
  • C.−3,−1,2,4
  • D.Every real number
C. Evaluate f at both endpoints and every interior critical number, then compare the four outputs.候选输入完整，才能保证全局比较完整。

Find Every Absolute Extremum

并列取得的最值位置要全部写出

f(x)=x³−3x on [−2,2]

Find the absolute maximum and minimum values and where each occurs.

Candidates: −2,−1,1,2. Values are −2,2,−2,2. The absolute maximum is 2 at x=−1,2; the absolute minimum is −2 at x=−2,1.同一最值可能在多个输入处取得。
