Connect Topic 2.1 to 2.2

From One Point to a Function

从某一点的导数，推广到整个导函数

At x=a

f′(a)=limh→0f(a+h)−f(a)h

One number: the tangent slope at one input.

一个点对应一个斜率。
At any x

f′(x)=limh→0f(x+h)−f(x)h

A new function: input x, output tangent slope.

每个 x 对应该点的切线斜率。

The variable h approaches zero; the input x remains free.h 趋近于 0，x 保留为自变量。

The derivative is itself a function.03

学生常把 x 也代成一个数。强调求 f′(x) 时，x 必须保留；只有求 f′(a) 时才代入具体 a。

The central definition

Definition of the Derivative

导数定义：先形成差商，再取极限

f′(x)=limh→0f(x+h)−f(x)h

1

Substitute

Build f(x+h) carefully.

把每个 x 换成 x+h。
2

Simplify

Factor or rationalize until h cancels.

化简并约去公共因子 h。
3

Take the limit

After cancellation, let h→0.

化简后才令 h 趋近于 0。
Do not substitute h=0 into the original quotient.04

明确原差商在 h=0 时无定义，但极限可能存在。流程是代入、化简、取极限，不能跳过极限符号。

Algebra before calculus

Build f(x+h) Correctly

括号是导数定义中最重要的代数习惯

f(x)=2x²−7x+1

f(x+h)=2(x+h)²−7(x+h)+1

=2x²+4xh+2h²−7x−7h+1

Not: 2x²+h−7x+h+1

Replace every occurrence of x by the entire quantity (x+h).每一个 x 都整体替换。

Correct substitution makes the later cancellation possible.05

先暂停，不急着求导，让学生检查平方和负号。官方讲义例 3 使用同一函数。

Official notes example

Derive f(x)=2x²−7x+1

用导数定义得到斜率公式

f′(x)=limh→02(x+h)²−7(x+h)+1−(2x²−7x+1)h

=limh→04xh+2h²−7hh=limh→0(4x+2h−7)

f′(x)=4x−7

The result accepts any input x and returns the tangent slope there.导函数的输出是原函数在该点的切线斜率。

Every numerator term contains h after like terms cancel.06

让学生说明为何可约 h：求极限时考虑 h 接近但不等于 0。最终得到 4x−7。

Different symbols · Same derivative

Derivative Notation

不同记号表达同一个导数

NotationHow to read itBest fit
f′(x)“f prime of x”Function named f
y′“y prime”Equation written y=…
dy/dx“the derivative of y with respect to x”Shows input and output variables
d/dx [f(x)]“differentiate f with respect to x”Operator notation

dy/dx is a single derivative symbol here; do not treat it as an ordinary fraction.本节先把 dy/dx 看作完整的导数记号。

Official practice · Context

Interpret Function and Derivative Values

函数值回答“有多少”，导数值回答“变化多快”

C(12)=3

C(t) is championships and t is years since 2002.

In 2014, the coach has won 3 championships.

2014 年时，冠军总数为 3。

C′(12)=0.4

At that time, the number of championships is increasing at 0.4 championship per year.

2014 年这一时刻，冠军数以每年 0.4 个的速率增加。

Do not say “after 12 years, the change is 0.4.” A derivative is a rate, so include “per year.”

Value units ÷ input units08

官方练习第 5 题。提醒学生 t=12 表示 2002 后 12 年，即 2014。导数解释必须包含 at that time 与单位。

Error clinic

Four Errors to Catch

四类高频错误

Lost parentheses

−f(x) must subtract the entire expression.

整体减去 f(x)。

Early substitution

Do not put h=0 into the original quotient.

不能一开始代 0。

Wrong tangent point

The point is (a,f(a)), not (a,f′(a)).

导数值是斜率。

Missing units

A contextual derivative has output-units per input-unit.

导数单位是“每”。

A correct final number with an invalid limit setup does not demonstrate the definition.定义题必须保留完整逻辑。

Structure first; arithmetic second.12

每组选择一个错误，写出对应的修正句。尤其检查分子 f(x+h)−f(x) 的第二项是否整体加括号。

Guided practice · Rational algebra

Differentiate f(x)=1/(x−2)

分式先通分，再约去 h

f′(x)=limh→01/(x+h−2)−1/(x−2)h

=limh→0−hh(x+h−2)(x−2)

f′(x)=−1(x−2)²,   x≠2

The domain restriction remains: the original function and its derivative are not defined at x=2.求导不会补上原函数不存在的点。

Common denominator → cancel h → limit13

对应官方练习第 4 题。通分后的分子是 (x−2)−(x+h−2)=−h，负号最易丢失。

Quick check · Multiple choice

Choose the Correct Definition

哪一个极限表示 f(x)=x²+1 的导数？

  • A.limh→0 [(x+h)²+1−x²+1]/h
  • B.limh→0 {[(x+h)²+1]−[x²+1]}/h
  • C.limx→0 [f(x+h)−f(x)]/h
  • D.[f(x+0)−f(x)]/0
B. It substitutes x+h everywhere, subtracts the entire f(x), divides by h, and lets h→0.括号、差商和 h→0 缺一不可。
Definition check: substitution · subtraction · quotient · limit14

答案 B。A 的常数项没有整体相减；C 让错误的变量趋近 0；D 直接除以 0。
