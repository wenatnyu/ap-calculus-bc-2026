Radius and Interval of Convergence of Power Series

幂级数的收敛半径与收敛区间

A power series behaves like a function only for input values where its numerical series converges.

先求开区间，再逐个检验端点。

Core lesson

Power Series Form

幂级数的一般形式

Σn=0∞an(x−c)n

The number c is the center. At x=c, every positive-power term vanishes, so the series converges at its center.

FlippedMath Version #1 · Unit 1003

If the starting index differs, the center still belongs whenever the individual defined terms make sense.

Core lesson

Three Radius Possibilities

收敛半径的三种情况

  • R=0: convergence only at the center
  • 0<R<∞: convergence for |x−c|<R, with endpoints undecided
  • R=∞: convergence for every real x
FlippedMath Version #1 · Unit 1004

The radius alone never decides finite endpoints.

Core lesson

Ratio Test for the Open Interval

用比值判别法求开区间

For terms un(x), solve

limn→∞|un+1(x)/un(x)|<1.

The result normally simplifies to |x−c|<R.

FlippedMath Version #1 · Unit 1005

The Ratio Test is inconclusive when the limit equals 1. That is exactly why endpoints need separate tests.

Core lesson

Radius Versus Interval

半径与区间的区别

If |x−2|<3, then R=3 and the open interval is −1<x<5.

The final interval might be (−1,5), [−1,5), (−1,5], or [−1,5].

Core lesson

Endpoint Tests

端点必须单独检验

Substitute each endpoint into the original series.

The result is now a numerical series. Use the appropriate test: p-series, alternating series, comparison, or the nth-term test.

左右端点可能有不同结论。

FlippedMath Version #1 · Unit 1007

Do not apply the absolute-value ratio inequality with ≤. At equality the Ratio Test says nothing.

Core lesson

Full Example with Endpoints

完整示例

For Σn=1∞(x−2)n/(n·3n), the Ratio Test gives |x−2|<3.

At x=5: Σ1/n diverges. At x=−1: Σ(−1)n/n converges.

R=3, interval [−1,5).

Core lesson

Radius Zero and Radius Infinity

半径为 0 或无穷

Σn!(x+1)n has ratio (n+1)|x+1|, so it converges only at x=−1: R=0.

Σ(x+1)n/n! has ratio tending to 0 for every x: R=∞.

FlippedMath Version #1 · Unit 1009

These examples make the factorial's position visible: numerator factorial shrinks the radius; denominator factorial expands it.

Core lesson

Geometric Structure

识别几何级数结构

Σ[(x−4)/2]n is geometric.

It converges when |(x−4)/2|<1, so 2<x<6.

At both endpoints the terms fail to approach zero. Thus R=2 and the interval is (2,6).

FlippedMath Version #1 · Unit 1010

Core lesson

Radius Alone Does Not Set Endpoints

只知道半径不能确定端点

If a power series centered at 0 has radius 5, then it converges for −5<x<5 and diverges for |x|>5.

No conclusion about x=−5 or x=5 follows without the coefficients.

Core lesson

Differentiation and Integration

逐项求导与积分后的收敛性

Term-by-term differentiation and integration preserve the radius of convergence.

Endpoint behavior may change, so test the new endpoint series again.

Example: Σxn has interval (−1,1), while its term-by-term integral Σxn+1/(n+1) converges on [−1,1).

FlippedMath Version #1 · Unit 1012

At x=-1 the integrated series is alternating harmonic; at x=1 it is harmonic.

Core lesson

Common Errors

常见错误

  • Reporting only |x−c|<R
  • Including endpoints without testing them
  • Using the Ratio Test when its limit equals 1
  • Confusing the center with the radius

Quick check · Reveal

Quick Check

课堂检测

Find the radius and interval of convergence of Σn=1∞(x−1)n/(n·4n).

Answer: The Ratio Test gives |x−1|<4. At x=5, Σ1/n diverges; at x=−3, Σ(−1)n/n converges. Thus R=4 and the interval is [−3,5).

Exit ticket

Exit Ticket

离堂检测

Find the interval of convergence of Σn=1∞n(x+2)n/5n.

Answer: The Ratio Test gives |x+2|<5, or −7<x<3. At either endpoint the terms have magnitude n, so they do not approach zero. The interval is (−7,3).
