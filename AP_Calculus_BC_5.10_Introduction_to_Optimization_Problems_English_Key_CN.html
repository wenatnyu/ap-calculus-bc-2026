Introduction to Optimization Problems

最优化问题入门：先建模

objective = what to maximize/minimize
constraint = what connects the variables
one-variable model + feasible domain

A correct optimization solution begins with a correct model.先写目标函数、约束条件和可行定义域，再求导。

Official strategy

The Optimization Workflow

官方五步建模流程

1

Draw and label.

2

Write the objective.

3

Use the constraint to reach one variable.

4–5

Differentiate, then verify candidates and endpoints.

Write the feasible domain before solving; it often comes directly from the geometry.长度、面积等通常必须为正。

Official-notes model

Largest Product with Fixed Sum

和固定时乘积最大

x+y=30

P=xy

y=30−x

P(x)=x(30−x)

x∈ℝ

Objective: product. Constraint: sum.用约束消去 y；原题未限制两数为正。

Official-notes model

Minimize Distance—Usually Distance Squared

最短距离通常改为最小化距离平方

point on y=√x: (x,√x)

fixed point: (5,0)

D=√((x−5)2+x)

D2=(x−5)2+x

x≥0

Because square root is increasing, minimizing D is equivalent to minimizing D².去掉根号可简化求导。

Constraint eliminates height

Surface Area as the Constraint

用表面积约束消去高

open box: x2+4xh=108

h=(108−x2)/(4x)

V=x2h

V(x)=27x−x3/4

0<x<√108

An open box has no top, so its surface-area equation contains one square base, not two.无盖盒只有一个正方形底面。

Margins change the outside dimensions

Minimize Paper Area

印刷面积固定，纸张面积最小

print area: xy=24 ⇒ y=24/x

A(x)=(x+2)(24/x+3)

x>0

Left/right margins add 2 inches total; top/bottom margins add 3 inches total.目标函数用纸张外框尺寸，不是印刷区尺寸。

A common constraint

Use Every Foot of Fence

三边围栏面积最大

2x+y=300

y=300−2x

A(x)=x(300−2x)

0<x<150

The wall replaces one side; only three sides use fencing.不要把约束误写成 2x+2y=300。

Symmetry matters

Largest Rectangle under y=6−x²

抛物线下对称矩形面积

upper-right corner: (x,6−x2)

width=2x, height=6−x2

A(x)=2x(6−x2)=12x−2x3

0≤x≤√6

The full width is 2x, not x.矩形跨过 y 轴。

Error check

Before You Differentiate

求导前四项检查

1

Is this the quantity requested?

2

Is the model in one variable?

3

Are all dimensions positive?

4

Did you include endpoints when feasible?

Attach units to the final optimized quantity—not just the variable.面积、体积、时间的单位不同。

AP-style modeling

Choose the Correct Objective

选择正确的一元目标函数

An open-top box is made from a 10-by-18 sheet by cutting x-inch squares from each corner. Which model should be maximized?

  1. Ax(10−x)(18−x)
  2. Bx(10−2x)(18−2x)
  3. C2x(10−x)(18−x)
  4. Dx²(28−4x)
Answer: B. The height is x, and each base dimension loses x from both ends. The domain is 0<x<5.两个底边方向都要减去 2x。

Exit ticket · Model only

Write the Objective and Domain

只建模，不求最优值

A rectangle has its base on the x-axis and upper corners on y=12−x². Write a one-variable area model and its feasible domain.

Answer: A(x)=2x(12−x²)=24x−2x³, with 0≤x≤√12.矩形宽为 2x，高为 12−x²。
