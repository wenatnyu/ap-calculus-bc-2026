AP Calculus BC · Topic 8.1

Average Value of a Function on an Interval

区间上函数的平均值

favg = (1/(b − a)) ∫ab f(x) dx

Average value is accumulated output divided by interval length. / 平均值就是总累积量除以区间长度。

The Formula

平均值公式

favg = 1/(b − a) · ∫ab f(x) dx

Use b − a, not b, and do not attach +C.

Units and Meaning

单位与含义

  • The integral has units of f × input.
  • Dividing by input units leaves the original units of f.
  • State the interval in a contextual interpretation.

Exact Example

精确计算示例

For f(x)=x² on [0,3]: favg = (1/3)∫₀³x²dx = 3

The result is a function value, not an area.

A Geometric Reading

几何理解

If ∫abf(x)dx = A, then favg=A/(b−a).

signed area = width × average height

Average Value of a Rate

变化率的平均值

average rate value = net change / elapsed time

For velocity, this equals average velocity, not average speed unless velocity never changes sign.

Mean Value Theorem for Integrals

积分中值定理

If f is continuous on [a,b], then some c in [a,b] satisfies

f(c)=favg

FlippedMath Version #1 · Unit 810

Continuity guarantees existence; it does not say the value of c is unique.

Locate the Point c

求对应的 c

For f(x)=x² on [0,3], favg=3, so c²=3 and c=√3.

Reject −√3 because it is outside [0,3].

The Average May Be Negative

平均值可以为负

Average value is not geometric area and need not be nonnegative.

Quick Check

课堂即时检测

Find the average value of f(x)=2x+1 on [1,4].

Answer: 6, because (1/3)∫₁⁴(2x+1)dx = (1/3)(18)=6.
