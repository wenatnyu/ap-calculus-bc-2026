Comparison Tests for Convergence

Core lesson

Direct Comparison: Convergence

直接比较证明收敛

If 0≤an≤bn eventually and Σbn converges, then Σan converges.

A smaller nonnegative series is controlled by a convergent upper bound.

FlippedMath Version #1 · Unit 1003

Say which series is the upper bound and name the benchmark theorem.

Direct Comparison: Divergence

直接比较证明发散

If 0≤bn≤an eventually and Σbn diverges, then Σan diverges.

A larger nonnegative series dominates a divergent lower bound.

FlippedMath Version #1 · Unit 1004

Students often reverse this direction; use 'large diverges, small converges' as a verbal check.

Core lesson

Convergence Example

直接比较收敛示例

0<1/(n2+3)≤1/n2.

Since Σ1/n2 converges, Σ1/(n2+3) converges.

FlippedMath Version #1 · Unit 1006

The larger denominator makes the original positive fraction smaller.

Divergence Example

直接比较发散示例

(n+1)/n2=1/n+1/n2≥1/n.

Since the harmonic series diverges, the original series diverges.

FlippedMath Version #1 · Unit 1007

A divergent lower bound is the correct direction for proving divergence.

Limit Comparison Test

极限比较判别法

If an,bn>0 and lim an/bn=L with 0<L<∞, then Σan and Σbn have the same behavior.

FlippedMath Version #1 · Unit 1008

Both positivity and a finite positive limit belong in the theorem statement.

Core lesson

Leading-Power Example

最高次项比较

Let an=(3n+2)/(n3-1) and bn=1/n2.

lim an/bn=3, so Σan converges.

FlippedMath Version #1 · Unit 1009

Start at a sufficiently large n so the denominator and all terms are positive.

Harmonic-Like Example

类似调和级数

Let an=(2n+5)/(n2+1) and bn=1/n.

lim an/bn=2, so Σan diverges.

FlippedMath Version #1 · Unit 1010

The ratio approaches a positive constant, so the lower-order terms do not change behavior.

Core lesson

Comparisons That Say Nothing

无效比较

  • Below a divergent series: inconclusive.
  • Above a convergent series: inconclusive.

The inequality must point in the theorem's useful direction.

FlippedMath Version #1 · Unit 1011

Give a counterexample for each invalid direction if students try to reason only from size.

Direct or Limit Comparison?

选直接比较还是极限比较

Use direct comparison when a clean inequality is easy.

Use limit comparison when rational or radical expressions share the same dominant behavior.

FlippedMath Version #1 · Unit 1012

Either test is valid when its hypotheses are verified; choose the clearer argument.

Comparison Workflow

比较判别流程

  1. Check nonnegative terms on a tail.
  2. Choose a known benchmark.
  3. Write a useful inequality or ratio limit.
  4. Name the benchmark behavior and conclude.
FlippedMath Version #1 · Unit 1013

A complete conclusion identifies both the benchmark and the comparison theorem.

Quick Check

课堂即时检测

Determine whether Σ1/(n2+n) converges.

Answer: Since 0<1/(n^2+n)≤1/n^2 and the p-series converges, the series converges by direct comparison.

Exit Ticket

离堂检测

Classify Σ(2n+5)/(n2+1) by limit comparison.

Answer: Compare with 1/n. The ratio tends to 2, and the harmonic series diverges, so the given series diverges.
