Same behavior · Different evidence

Four Views of One Limit

四种表示，描述同一个“附近趋势”

Graph

Trace the curve toward x=c from both sides. Read the height approached.

看曲线左右靠近时的高度。

Table

Read outputs for inputs just below and just above c.

看 c 左右附近的函数值。

Algebra

Study an equivalent expression for nearby x≠c.

研究点附近的等价式。

Words

State what f(x) approaches as x approaches c.

用语言说出趋近关系。

The target is nearby behavior. A representation may assign any value at x=c without changing the limit.极限关注附近；点上的函数值可以不同。

Representations are consistent when they describe the same approach.03

让学生给四个名词各配一个动作：trace, read, simplify, describe。强调所有动作都围绕 x 接近 c，而不是只看 x=c。

A routine across all representations

Use the Same Four Questions Every Time

无论看到哪种表示，都按同一顺序判断

01

From the left?

What value does f(x) approach as x→c−?

左极限是多少？
02

From the right?

What value does f(x) approach as x→c+?

右极限是多少？
03

Do they agree?

If the one-sided limits match, the two-sided limit exists.

左右相等，双侧极限才存在。
04

What about f(c)?

Record it separately. It does not decide the limit.

点值单独记录，不替代极限。
Left · Right · Compare · Separate the point value04

四个问题要求学生背熟。以后所有图表题先写左右极限，再写双侧极限，最后才看 f(c)。

Representation 1 · Algebra

Algebra Shows the Nearby Rule

代数式说明点附近遵循什么规律

f(x) = { x−5x²−6x+5, x≠5
4, x=5 }
x−5(x−5)(x−1) = 1x−1   for x≠5

Read two different facts

limx→5f(x)=1/4, because nearby outputs follow 1/(x−1).

f(5)=4, because the second piece assigns 4 at the point.

Limit: 1/4. Function value: 4.极限值 1/4；函数值 4。

Official packet 7a · The value at x=5 does not enter the limit calculation.05

板书因式分解 x²−6x+5=(x−5)(x−1)。分子分母约去 x−5 后，附近表达式是 1/(x−1)，所以极限 1/4；点值仍是 4。

Representation 2 · Table

A Table Uses Nearby Entries

表格看“靠近点”的数，不只看点上的数

Given: the two pieces between the listed points are linear.题设：表中两段均为线性分段。

x4.84.94.99955.0015.15.2
f(x)00.20.24940.2510.30.5

From the left: the nearby values move toward 0.25.左侧趋近 0.25。

From the right: the nearby values move toward 0.25.右侧也趋近 0.25。

The entry f(5)=4 is not part of the approaching pattern. Therefore limx→5f(x)=1/4.表格中间一格是点值，不决定极限。

Official packet 7b · Read inward from both sides.06

让学生用手指从表格左右两边向 x=5 移动。0.249 与 0.251 才是最有力的附近证据，中间的 4 是 f(5)。官方答案认为该表可以表示极限 1/4。

Representation 3 · Graph

A Graph Separates the Hole from the Point

空心点显示趋近位置；实心点显示函数值

Read the curve, then the point

The curve approaches the open circle at height 1/4 from both sides.

The closed point gives the separate fact f(5)=4.

limx→5f(x)=1/4 while f(5)=4.沿曲线看极限；看实心点读函数值。

Do not jump from a closed point to a limit statement.07

先遮住实心点问极限，再遮住曲线只问 f(5)。图像上这两个信息由不同符号承担：空心点对应附近趋势，实心点对应点值。

Representation 4 · Verbal

Words Must Name the Approach

文字描述要说清“谁趋近谁”

“As x approaches 5 from either side, f(x) approaches 1/4.”

“At x=5, the function is assigned the value 4.”

First sentence: a limit statement.第一句描述极限。

Second sentence: a function-value statement.第二句描述函数值。

Precise language keeps two true statements from being mixed together.

Say “approaches” for a limit and “equals” for an assigned point value.08

要求学生完整读两句英文。纠正 “the limit equals f(5)” 这种自动绑定。可以让学生把 graph/table/algebra 三页各改写成这两句 verbal statements。

Official packet 8 · Target limit 6

Test Each Representation Against the Claim

已知极限为 6，逐一核对每种表示

A · Algebra

x²−x−6x−3, x≠3;   g(3)=6

(x−3)(x+2)/(x−3)→5.

NO · limit is 5

B · Table

Left-side entries move toward 6, but right-side entries move toward 5.

6 ≠ 5

NO · sides disagree

C · Graph

Both branches approach the open circle at (3,6). A closed point sits at (3,3).

YES · limit is 6

Check the claimed limit, not the label at the point.核对的是趋近值，不是点上的标签。

Official answers: A no · B no · C yes09

官方第 8 题答案 a/b no, c yes。A 的点值虽为 6，但极限为 5；B 左右趋势不同；C 两侧曲线都趋近空心点 y=6，实心点 y=3 不影响极限。

One-sided limits decide the two-sided limit

A Two-Sided Limit Needs Agreement

双侧极限存在的条件：左右极限相等

limx→c−f(x)=L
limx→c+f(x)=L
⇒ limx→cf(x)=L
limx→c−f(x)=A
limx→c+f(x)=B
A≠B ⇒ two-sided limit DNE

DNE does not mean that neither side has a limit. The one-sided limits may both exist but be different.DNE 可能是左右极限各自存在，但数值不同。

For piecewise graphs and tables, approach the break from each side separately.10

用手势表示 x 从左右接近 c。先写两个单侧结论，不能直接从跳跃点写 DNE。双侧 DNE 时，单侧极限仍可能各自存在。

One-sided limits · Sign first

Absolute Value Turns the Side into a Sign

绝对值商：先判断括号内的正负

Condition on u|u||u| / uu / |u|
u<0−u−1−1
u>0u+1+1
limx→4−|x−4|x−4
x<4 ⇒ x−4<0
= −1

Use the side information

For u=x−a, approaching a from the left makes u<0; approaching from the right makes u>0.

Do not substitute x=a. The quotient is undefined there; its nearby sign is the evidence.不能代入点；要看附近的符号。

Official notes 2 · Left of 4 gives a negative denominator.11

官方 Notes 第 2 题答案 −1。让学生先说 x−4 是 negative，再处理绝对值。强调规则依赖 u 的符号；这里 u=x−a，所以左右方向能直接判断。

Official practice 10 · Piecewise and absolute value

A Point Value Still Does Not Control the Limit

即使给出点值，极限仍由附近表达式决定

f(x) = { (x−3)²(x²+1)|x−3|, x≠3
2, x=3 }
  • A.0
  • B.2
  • C.10
  • D.DNE

Simplify safely

(x−3)²|x−3| = |x−3|

f(x)=|x−3|(x²+1),   x≠3

A · 0. As x→3, |x−3|→0 and x²+1→10, so the product approaches 0. The assigned value f(3)=2 is irrelevant to the limit.附近式趋近 0；点值 2 不替代极限。
Both sides are nonnegative and approach 0.13

官方第 10 题选 A。特别避免把 (x−3)²/|x−3| 错写成 x−3；正确化简为 |x−3|。两侧都趋近 0，f(3)=2 只说明点值。

Official practice 9 · Piecewise linear

Which Representation Shows DNE?

哪一种表示能说明 x→4 时双侧极限不存在？

A · Piecewise rule

h(x)={ ½x+3, x<4
13−2x, x>4 }

Both pieces approach 5 at x=4.

B · Table

Both linear patterns extend toward 5 at x=4, even though the listed point value is 1.

left→5; right→5

C · Graph

The left branch approaches a lower open point; the right branch approaches a higher closed point.

left ≠ right

A: no · B: no · C: yes. A and B both have matching one-sided limits. Only graph C shows different heights from the two sides, so only C has a two-sided limit that does not exist.A、B 的左右趋势相同；只有 C 左右高度不同。
Official answers: A no · B no · C yes14

官方第 9 题答案 a/b no, c yes。A 左右代入都得 5；B 两边线性趋势也都延伸到 5，x=4 的点值 1 不影响极限；C 图像左右高度不同。
