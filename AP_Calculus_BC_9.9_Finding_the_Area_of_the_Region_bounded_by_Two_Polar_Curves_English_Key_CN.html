Core lesson

Outer Sector Minus Inner Sector

外扇形减内扇形

dA≈(1/2)(R²−r²)dθ

  1. Choose an angular interval.
  2. Identify the farther and nearer radial boundaries.
  3. Square each radius separately.
  4. Integrate and include the factor 1/2.
FlippedMath Version #1 · Unit 903

The subtraction is R²−r², never (R−r)². Have students state which curve is outer before writing an integral.

Core lesson

Find and Verify Intersections

求出并验证交点

For same-angle, nonnegative radial traces, start with R(θ)=r(θ).

2cosθ=1 gives θ=±π/3 on the right half-plane.

Then verify the Cartesian point or graph. Negative-radius equivalence means equality of formulas is not a universal intersection test.

FlippedMath Version #1 · Unit 904

This caveat matters: distinct polar pairs can name the same point. For standard positive radial comparisons, equality remains the natural first step.

Core lesson

Worked Region: Outside r=1, Inside r=2cosθ

例题：单位圆外、右侧圆内

The curves meet at θ=±π/3. On this interval, 2cosθ≥1.

A=(1/2)∫−π/3π/3(4cos²θ−1)dθ

A=π/3+√3/2

FlippedMath Version #1 · Unit 905

Core lesson

Test Radial Order

检验哪条曲线在外

Between consecutive intersection angles, choose a test angle and compare geometric radii.

For r₁=1 and r₂=2sinθ on [0,π/2], equality occurs at θ=π/6.

At θ=0, r₁ is outer. At θ=π/2, r₂ is outer.

FlippedMath Version #1 · Unit 906

A graph is helpful, but a test-angle comparison makes the outer/inner decision explicit and auditable.

Core lesson

Split When Outer and Inner Switch

外内曲线交换时必须分段

For r₁=1 and r₂=2sinθ on 0≤θ≤π/2:

A=(1/2)[∫₀^{π/6}(1−4sin²θ)dθ + ∫π/6π/2(4sin²θ−1)dθ]

A=π/12+√3/2

FlippedMath Version #1 · Unit 907

Without the split, signed cancellation gives the wrong geometric area. Check that each integrand is nonnegative on its own interval.

Core lesson

Inside One, Outside Another

一条曲线内、另一条曲线外

Translate the words ray by ray:

  • inside R: radial distance ≤ R(θ)
  • outside r: radial distance ≥ r(θ)

The requested region exists only where the inside boundary is at least as large as the outside boundary.

FlippedMath Version #1 · Unit 908

Ask students to shade one representative ray segment. This converts verbal region language into outer-minus-inner bounds.

Core lesson

Negative Radius Can Hide an Intersection

负半径可能隐藏交点

Polar coordinates are nonunique: (r,θ) and (−r,θ+π) represent the same point.

The equations r=1 and r=−1 describe the same unit circle as sets, even though 1=−1 has no solution.

Verify suspect intersections in Cartesian coordinates or from the traced graph.

FlippedMath Version #1 · Unit 909

Use this conceptual example to prevent an overgeneralized 'set the radii equal' rule. Standard AP problems often use intervals where radii are nonnegative, but the condition must be checked.

Core lesson

Symmetry and Multiple Intervals

对称性与多个区间

  • Find all relevant crossings in one full trace.
  • Identify every disjoint angular interval belonging to the requested region.
  • Use symmetry only for nonoverlapping congruent pieces.
  • Check that negative r does not map an interval onto an already-counted region.
FlippedMath Version #1 · Unit 910

A correct-looking factor of two can still double-count. Require students to state which two regions are congruent.

Core lesson

A Specified Sector Between Curves

指定扇区内两曲线之间的面积

On 0≤θ≤π/3, r=2 is outside r=2cosθ.

A=(1/2)∫₀^{π/3}(4−4cos²θ)dθ

A=π/3−√3/4

A test at θ=π/6 confirms 2≥√3.

Core lesson

Numerical Intersections

数值求交点

  1. Graph both polar curves in radian mode.
  2. Bracket each crossing.
  3. Solve to full calculator precision.
  4. Test radial order between consecutive crossings.
  5. Use stored values as integration bounds; round only the final answer.
FlippedMath Version #1 · Unit 912

Warn that a polar graphing window can hide small loops. Students should use algebraic zeros and symmetry alongside the graph.

Core lesson

Final Setup Checklist

最终设式检查单

  1. Sketch and mark the requested region.
  2. Find and verify all relevant intersection angles.
  3. Test outer and inner radii on every interval.
  4. Split whenever their order changes.
  5. Write one-half times outer squared minus inner squared.
  6. Check trace, overlap, units, and reasonableness.
FlippedMath Version #1 · Unit 913

Have students read the integrand aloud as 'outer sector minus inner sector.' This catches both missing squares and reversed order.
