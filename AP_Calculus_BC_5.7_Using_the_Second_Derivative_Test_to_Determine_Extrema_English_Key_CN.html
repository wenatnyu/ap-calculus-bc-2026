AP Calculus BC · Topic 5.7

Using the Second Derivative Test to Determine Extrema

用二阶导数检验判断极值

At a critical number c with f′(c)=0:
f″(c)>0 ⟹ local min
f″(c)<0 ⟹ local max

Concavity classifies a horizontal critical point—unless the second derivative equals zero.凹向可以分类水平临界点；二阶导为零时无法判断。

Four-step method

A Reliable SDT Workflow

一阶导找点，二阶导做分类

1

Find f′(x).

2

Solve f′(c)=0.

3

Compute f″(c) at each candidate.

4

Classify or switch methods if the result is 0.

Evaluate f(c) only after classification when the question asks for the extremum point or value.横坐标分类完成后再求纵坐标。

Essential caution

When f″(c)=0, Change Methods

无法判定不等于没有极值

f(x)=x⁴

f′(0)=0, f″(0)=0

0 is a local minimum.

g(x)=x³

g′(0)=0, g″(0)=0

0 is neither.

The same SDT result can hide different behaviors. Use the First Derivative Test or analyze the function directly.二阶导为零后必须换方法。

Inconclusive ≠ no extremum07

成对反例说明 f″(c)=0 无法判定。让学生明确“inconclusive”只描述这项检验。

Official practice · Constant curvature

A Perfect Square

二阶导恒正，唯一驻点为极小

h(x)=(2x−5)²

h′(x)=4(2x−5)=0 ⟹ x=5/2

h″(x)=8>0

h has a relative minimum at x=5/2; the minimum point is (5/2,0).恒凹向上，加上水平切线即可判极小。

Official notes · Global conclusion

One Critical Point Can Settle the Global Question

唯一临界点若确为极值，则在本课连续区间情境中为绝对极值

On the connected interval considered in the official notes, if a function has only one critical point and that point is an extremum, then it is an absolute extremum.

There is no second interior turn that could create a higher peak or lower valley.

Still check the stated domain and hypotheses before extending the claim to a different setting.

结论依赖题设的连续区间语境。

First versus second derivative

Choose the Better Test

两种方法的输入信息不同

SituationBest first choiceReason
f′ is factored and signs are easyFirst Derivative TestDirectly shows the direction change.
f″(c) is easy and nonzeroSecond Derivative TestFast classification at a stationary point.
f″(c)=0First Derivative TestSDT is inconclusive.
f′(c) DNEFirst Derivative TestSDT hypothesis is not met.

Both valid tests must agree when both apply.选择更省力的方法，但结论应一致。

Match the method to the available information.12

Official test prep · Treat f′ as a function

Find the Maximum Value of f′

要求导函数的最大值，就把 f′ 当作目标函数

f(x)=3x²−x³

f′(x)=6x−3x²

f″(x)=6−6x=0 ⟹ x=1

f‴(x)=−6<0

f′ has a local maximum at x=1, and the maximum value is f′(1)=3.目标函数是 f′，其一阶、二阶导分别是 f″、f‴。

Official test prep · Multiple minima

Where Are the Relative Minima?

先解 f′=0，再逐点代入 f″

f(x)=x⁴−8x²

  • A.x=0 only
  • B.x=−2 only
  • C.x=2 only
  • D.x=−2 and x=2
D. f′=4x(x²−4) gives c=−2,0,2. Since f″=12x²−16, f″(±2)=32>0 and f″(0)=−16<0. Thus the minima occur at x=±2.x=0 是局部最大，不是极小。
