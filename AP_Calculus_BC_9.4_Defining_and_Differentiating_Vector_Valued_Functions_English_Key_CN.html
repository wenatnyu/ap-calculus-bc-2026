Vectors: Magnitude and Direction

向量的大小与方向

For v=⟨a,b⟩, magnitude is ||v||=√(a²+b²).

Equal vectors have the same components and magnitude. Equal nonzero vectors also have the same direction.

Position as a Vector Function

位置向量函数

r(t)=⟨x(t),y(t)⟩ locates a particle in the plane. Its tip traces the same parametric curve defined by x(t), y(t).

Differentiate Componentwise

逐分量求导

r′(t)=⟨x′(t),y′(t)⟩.

If the components are differentiable, the vector function is differentiable.

Velocity and Acceleration

速度与加速度

v(t)=r′(t) and a(t)=v′(t)=r″(t).

速度是位置的导数；加速度是速度的导数。

Derivative Rules Still Work

向量函数的求导法则

Sums, differences, and scalar multiples are differentiated componentwise.

[f(t)r(t)]′=f′(t)r(t)+f(t)r′(t).

Tangent Direction

When r′(t₀)≠0, the velocity vector is tangent to the path at r(t₀) and points in the direction of increasing t.

Slope from the Velocity Vector

由速度向量求轨迹斜率

If v=⟨vx,vy⟩ and vx≠0, then dy/dx=vy/vx.

Common Traps

常见错误

  • Dropping angle brackets.
  • Differentiating only one component.
  • Calling a zero vector a direction.

Reveal: Derivative Vector

揭晓：向量导数

Try it. Let r(t)=⟨t²et, cos(2t)⟩. Find r′(0).

Answer. r′(t)=⟨et(t²+2t), −2sin(2t)⟩, so r′(0)=⟨0,0⟩.

Reveal: Velocity and Slope

揭晓：速度与斜率

Try it. For r(t)=⟨t³−t, t²+1⟩, find the velocity vector and path slope at t=1.

Answer. v(1)=⟨2,2⟩; because the x-component is nonzero, dy/dx=2/2=1.
