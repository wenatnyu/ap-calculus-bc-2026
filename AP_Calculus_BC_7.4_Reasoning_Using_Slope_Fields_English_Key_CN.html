Core lesson

Equilibrium Solutions Are Horizontal

平衡解是水平曲线

y′=0.5y

When y=0, every segment is horizontal, so y=0 is a solution.

y>0 ⇒ y′>0: curves rise.

y<0 ⇒ y′<0: curves fall.

自治方程的平衡解来自 g(y)=0。

Core lesson

Can Two Solution Curves Cross?

两条解曲线能否相交

At one point, the field assigns one slope.

For the standard smooth differential equations used here, an initial point determines one local solution. Distinct solution curves therefore do not cross.

This conclusion relies on a local uniqueness condition; it is not a rule for every imaginable differential equation.在本课常见的光滑情形下，解曲线不相交。

Core lesson

Concavity Along a Solution

沿解曲线判断凹凸

Visual method

Follow one curve and watch whether its slopes increase or decrease.

Algebraic method

If y′=F(x,y), then y″=Fₓ+Fᵧy′.

Compare slopes along the trajectory—not across a fixed horizontal row.凹凸性要沿同一条解曲线观察。

Core lesson

Autonomous Fields Repeat by Row

自治方程按横行重复

y′=g(y)

The direction depends only on height, so each horizontal row has the same slope.

Use the sign of g(y) above and below equilibria to see whether solutions move toward or away from them.平衡线两侧的箭头判断稳定性。

Core lesson

Equilibria Can Act as Barriers

平衡解可以形成屏障

y′=y(2−y)

The horizontal curves y=0 and y=2 are solutions. Under uniqueness, another solution cannot cross either one.

For 0<y<2, slopes are positive, so solutions rise toward y=2.解会靠近平衡线，但不会穿过。

Locate Nonnegative Slopes

找非负斜率区域

For y′=y²(x−1), where are slopes nonnegative?

Answer: Because y²≥0, slopes are nonnegative when x≥1, and also at every point on y=0.别漏掉 y=0 时乘积为零。
