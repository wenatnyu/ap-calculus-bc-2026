Practice

Quick Practice 快速练习

Logarithms · 对数

  1. Evaluate: log232.
    Answer

    5, because 25=32.

  2. Expand: ln(3x²/√y).
    Answer

    ln 3 + 2ln x − ½ln y.

  3. Condense: 2ln x − ln(x−1).
    Answer

    ln(x²/(x−1)).

  4. Solve: 32x−1=27.
    Answer

    27=3³, so 2x−1=3 and x=2.

  5. Solve: ln(x−2)=1.
    Answer

    x−2=e, so x=e+2.

  6. Find the domain: f(x)=ln(5−2x).
    Answer

    5−2x>0, so x<5/2.

Trigonometry · 三角函数

  1. Convert 225° to radians.
    Answer

    225°·π/180° = 5π/4.

  2. Find sin(5π/6), cos(5π/6), and tan(5π/6).
    Answer

    1/2, −√3/2, −√3/3.

  3. Simplify: (1−cos²x)/sin x.
    Answer

    sin²x/sin x = sin x (where defined).

  4. Solve sin x=√3/2 on [0,2π).
    Answer

    x=π/3, 2π/3.

  5. For y=−3cos(2x)+1, give amplitude, period, and midline.
    Answer

    Amplitude 3; period π; midline y=1.

  6. Evaluate: arctan(−1).
    Answer

    −π/4.
