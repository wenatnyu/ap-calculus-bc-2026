Identities · 恒等式

tan x = sin xcos x
cot x = cos xsin x
sec x = 1/cos x
csc x = 1/sin x
sin²x + cos²x = 1
1 + tan²x = sec²x
1 + cot²x = csc²x

Half-Angle & Sum-to-Product

sin²(A/2) = 1 − cos A2,   cos²(A/2) = 1 + cos A2
sin A + sin B = 2 sin((A+B)/2) cos((A−B)/2)

cos A + cos B = 2 cos((A+B)/2) cos((A−B)/2)
cos A − cos B = −2 sin((A+B)/2) sin((A−B)/2)

Quick Practice 快速练习

Logarithms · 对数

  1. Evaluate: log232.
    Answer

    5, because 25=32.

  2. Expand: ln(3x2y).
    Answer

    ln3+2lnx−12lny.

  3. Condense: 2lnx−ln(x−1).
    Answer

    ln(x2x−1).

  4. Solve: 32x−1=27.
    Answer

    27=33, so 2x−1=3 and x=2.

  5. Solve: ln(x−2)=1.
    Answer

    x−2=e, so x=e+2.

  6. Find the domain: f(x)=ln(5−2x).
    Answer

    5−2x>0, so x<52.

Trigonometry · 三角函数

  1. Convert 225° to radians.
    Answer

    225°·π180°=54π.

  2. Find sin(5π/6), cos(5π/6), and tan(5π/6).
    Answer

    12, −32, −33.

  3. Simplify: 1−cos2xsinx.
    Answer

    sin2xsinx=sinx (where defined).

  4. Solve sinx=32 on [0,2π).
    Answer

    x=π3,2π3.

  5. For y=−3cos(2x)+1, give amplitude, period, and midline.
    Answer

    Amplitude 3; period π; midline y=1.

  6. Evaluate: tan−1(−1).
    Answer

    −π4.
