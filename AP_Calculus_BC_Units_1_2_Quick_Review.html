Rate of Change & Definition

Average rate = f(b) − f(a)b − aSlope of a secant line · 割线斜率
f′(a) = limh→0 f(a+h) − f(a)h
f′(x) = limh→0 f(x+h) − f(x)h
Differentiable ⇒ Continuous可导必连续；连续不一定可导。

Basic Rules · 基本法则

(c)′ = 0
(xn)′ = nxn−1
(cf)′ = cf′
(f ± g)′ = f′ ± g′
(fg)′ = f′g + fg′
(fg)′ = f′g − fg′g²

Essential Derivatives · 必背导数

(sin x)′ = cos x
(cos x)′ = −sin x
(ex)′ = ex
(ln x)′ = 1x
(tan x)′ = sec²x
(cot x)′ = −csc²x
(sec x)′ = sec x tan x
(csc x)′ = −csc x cot x
