# AP Calculus BC · Unit 1 course site

Current scope: Topics 1.1–1.7.

Each topic follows one classroom sequence:

1. Review Quiz — questions, answers and explanations in one HTML file.
2. Class Notes — English-first slides with key Chinese support.
3. Notes Answers — the same slides opened with `?answers=show`.
4. CA #1 Homework — linked to the official FlippedMath PDF.

Open `index.html` locally or through GitHub Pages.

## Classroom tools

- Random Question — 42 English-first prompts covering Topics 1.1–1.7, with key Chinese hints and toggle answers.
- Student Picker — six confirmed formal-name/WeChat-profile pairs with avatars, no-repeat rounds, and an attendance switch.

## Keyboard controls for class notes

- `←` / `→`, Page Up / Page Down: navigate
- `Space`: next slide
- `N`: speaker notes
- `F`: full screen
- `P`: print
