Extend the point definition

From One Point to an Entire Interval

区间上连续 = 区间内每一点都连续

A function is continuous on an open interval if it is continuous at every point in that interval.

开区间内每一点都必须连续。

Closed endpoint: use the one-sided limit from inside the interval.

Interior point: use the ordinary two-sided definition.

Excluded input: the function cannot be continuous there.

Pointwise continuity repeated across an interval.03

本节官方材料主要通过定义域确认连续区间。补充闭区间端点使用区间内部的单侧连续。

Official notes 1

Cancellation Does Not Restore an Input

约分不能把原式排除的点加回来

f(x)=x²−xx

=x−1,   but only for x≠0

Original restriction: x≠0.

Domain: (−∞,0)∪(0,∞).

The graph is the line y=x−1 with a hole at x=0.

化简式连续，但原函数在 x=0 仍无定义。
Official notes 107

强调 domain 来自原式。x=0 的因子虽约掉，但仍形成空洞。

Official notes 2

Intersect All Restrictions

同时有根式与分母时，取条件交集

f(x)=3x√(x+5)x

x+5≥0   and   x≠0

x≥−5,   x≠0

Domain: [−5,0)∪(0,∞).

The radical endpoint −5 is included; the denominator zero 0 is excluded.根式端点可取，分母零点不可取。

Official notes 208

即使分子含 x，也不能与分母约掉后恢复 x=0。两个限制要取交集。

Official notes 3

A Root Can Be Defined but Still Zero the Denominator

根式有定义，不代表整个分母非零

h(x)=52−√x

x≥0

2−√x≠0

√x≠2 ⇒ x≠4

Domain: [0,4)∪(4,∞).

x=4 satisfies the root rule but fails the denominator rule.x=4 时根式合法，但整个分母为0。

Official notes 309

分两层检查：先 x≥0，再排除使2−√x=0的x=4。

The Entire Log Argument Must Be Positive

对数内部是商，就判断整个商的符号

Official practice 5

Root Rule + Two Denominator Zeros

先取根式条件，再排除分母零点

h(t)=√(t−1)t²−2t−48

t−1≥0

t²−2t−48=(t−8)(t+6)

t≥1, while the denominator excludes t=8 and t=−6.

The root restriction already removes −6.

[1,8)∪(8,∞).先保留 t≥1，再从中排除8。
Official practice 511

Official practice 2

Keep Every Zero of the Original Denominator

被约掉的因子仍然对应原函数的空洞

f(x)=x−7x²−9x+14

=x−7(x−7)(x−2)

=1x−2,   x≠7

Exclude x=2 and x=7.

Domain: (−∞,2)∪(2,7)∪(7,∞).

x=2 is a vertical asymptote; x=7 is a hole.两点都切断连续区间，但类型不同。

Official practice 212

官方答案排除2与7。原定义域要在化简前确定。

Official notes 5 · Check boundaries and internal restrictions

Where Is This Piecewise Function Continuous?

分段函数既要查交界点，也要查每段内部限制

f(x)=x²−2x−1/7x≤0      3/(x−7)0<x≤3      (7x−15)/(4x−20)x>3

At x=0: left value −1/7; right limit −3/7. Jump.

At x=3: both sides equal −3/4. Continuous.

At x=5: denominator 4x−20=0. Vertical asymptote.

(−∞,0)∪(0,5)∪(5,∞).x=3 不切断区间，因为函数在该点连续。
Official notes 513

核对：0处 -1/7 与 -3/7 不同；3处 3/(−4)=−3/4 且(21−15)/(12−20)=−3/4；第三段在5处分母为0。
