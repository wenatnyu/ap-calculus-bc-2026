Core lesson

Operations Inside the Radius

收敛半径内部的逐项运算

If f(x)=Σan(x−c)n has radius R, then its derivative and antiderivative series also have radius R.

Within |x−c|<R, term-by-term calculus is valid.

FlippedMath Version #1 · Unit 1003

The radius stays the same, but endpoint convergence may change. Save endpoint claims until after testing the new series.

Core lesson

Term-by-Term Differentiation

逐项求导公式

If f(x)=Σn=0∞an(x−c)n, then

f′(x)=Σn=1∞n an(x−c)n−1.

The constant term disappears, and the starting index usually changes.

Term-by-Term Integration

逐项积分公式

∫f(x)dx=C+Σn=0∞an(x−c)n+1/(n+1).

A definite integral or an initial condition determines the constant.

不定积分不能漏掉 C。

FlippedMath Version #1 · Unit 1005

For an integral from c to x, the constant is automatically chosen so the new function equals zero at x=c.

Differentiating an Existing Series

Let f(x)=Σn=1∞x2n/n!.

Core lesson

A Rational Function from Geometry

由几何级数表示有理函数

Start with 1/(1+u)=Σ(−1)nun.

Set u=x² and multiply by x²:

x²/(1+x²)=x²−x⁴+x⁶−x⁸+⋯=Σ(−1)nx2n+2.

Validity: |x|<1.

FlippedMath Version #1 · Unit 1007

The geometric condition is |x²|<1, equivalent to |x|<1. Both endpoints fail the nth-term test for this series.

Core lesson

Integrating cos(t⁶)

逐项积分 cos(t⁶)

cos(t⁶)=Σn=0∞(−1)nt12n/(2n)!.

∫0xcos(t⁶)dt=Σn=0∞(−1)nx12n+1/[(2n)!(12n+1)].

First terms: x−x¹³/(2!·13)+x²⁵/(4!·25)−x³⁷/(6!·37)+⋯.

FlippedMath Version #1 · Unit 1008

The exponent comes from integrating t^(12n), so both exponent and denominator gain 1.

Core lesson

Initial Condition after Integration

积分后使用初始条件

If f′(x)=e3x and f(0)=0, then

e3x=Σ3nxn/n!.

f(x)=Σn=0∞3nxn+1/[(n+1)n!]

=x+(3/2)x²+(3/2)x³+(9/8)x⁴+⋯.

FlippedMath Version #1 · Unit 1009

The initial condition makes C=0. If f(0) were not zero, add that constant.

Differentiating a Taylor Polynomial

对泰勒多项式求导

Let T(x)=7−3h+5h²−2h³+6h⁴, where h=x−3.

T′(x)=−3+10h−6h²+24h³.

At x=3.3, h=0.3 and T′(3.3)=0.108.

FlippedMath Version #1 · Unit 1010

Because dh/dx=1, powers of h differentiate normally. This is the final problem in the official end review.

Core lesson

Products and Coefficients

级数乘积与系数

To find a requested coefficient, multiply only terms whose degrees can combine to that power.

sin x=x−x³/6+x⁵/120−⋯

sin²x=x²−x⁴/3+2x⁶/45−⋯

The coefficient of x⁴ is −1/3.

FlippedMath Version #1 · Unit 1011

For x^4, only 2·x·(-x^3/6) contributes. For higher powers, list all degree pairs before multiplying.

Core lesson

Radius Stays, Endpoints May Change

半径不变，端点可能改变

Differentiation and integration keep the same radius of convergence.

They can change endpoint behavior because the coefficients gain factors of n or 1/(n+1).

运算后重新检验两个端点。

FlippedMath Version #1 · Unit 1012

Use the geometric series and its integral as a quick example: (−1,1) becomes [−1,1) after integration from 0.

Core lesson

Common Errors

常见错误

  • Forgetting the integration constant or initial condition
  • Changing the exponent without changing its coefficient
  • Reindexing before checking the first few terms
  • Carrying old endpoint conclusions into a new series

Quick Check

课堂检测

Write the first four nonzero terms, a general term, and the interval of convergence for x²/(1+x²).

Answer: x²−x⁴+x⁶−x⁸+⋯=Σn=0∞(−1)nx2n+2. It converges for |x|<1, so the interval is (−1,1).
FlippedMath Version #1 · Unit 1014

At x=±1 the terms are ±1 in sign but do not approach zero, so both endpoints diverge.
