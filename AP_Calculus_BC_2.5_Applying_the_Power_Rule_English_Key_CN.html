Applying the Power Rule

应用幂法则求导

For a constant exponent, multiply by the exponent and reduce the exponent by one.指数乘到前面，原指数减 1。

ddx(xⁿ)=nxⁿ⁻¹
n is constant
integer powers · roots · reciprocals · tangent lines

One rule · Two actions

The Power Rule

幂法则的两个动作

If f(x)=xⁿ, then f′(x)=nxⁿ⁻¹.

× n

New coefficient

Multiply the old coefficient by the exponent.

原系数乘指数。
n − 1

New exponent

Subtract exactly one, including when n is negative or fractional.

指数统一减 1。

Do not multiply the exponent by one less: the new exponent is n−1, not n(n−1).

Coefficient change and exponent change are separate actions.04

用 y=x³⁷ 与 y=x⁹ 做口算。要求先说“系数、指数”再落笔。

Reciprocals are powers

Negative Exponents

分母中的 x 改写为负指数

y=1x⁵=x⁻⁵

y′=−5x⁻⁶=−5x⁶

Exponent arithmetic: −5−1=−6, not −4.负指数再减 1，会更负。

The domain still excludes x=0.

Rewrite → differentiate → rewrite if desired05

Roots are powers

Fractional Exponents

根式改写为分数指数

Square root

√x=x1/2

ddx√x=12x−1/2=12√x

1/2−1=−1/2。

Cube root

∛x=x1/3

ddx∛x=13x−2/3=13∛(x²)

1/3−1=−2/3。

At x=0, these derivative formulas are undefined even though the original root functions may be defined there.

Denominator of the exponent tells the root.06

联系 2.4：√x 在端点 0 不具有普通两侧导数；∛x 在 0 有竖直切线，导数不是有限数。

Constant means constant

The Exponent May Be Irrational

π 与 e 也是常数

y=xπ

y′=πxπ−1

π 是固定指数。

y=xe

y′=exe−1

e 也是固定指数。

Do not confuse xe with ex. The first uses the power rule; the second is an exponential function covered in Topic 2.7.底数和指数的位置决定规则。

Official tricky examples

Simplify First

先把整个函数化成一个幂

Cancel powers

f(x)=x√x=x1/2,   x>0

f′(x)=12√x,   f′(7)=12√7

x¹/x¹ᐟ²=x¹ᐟ²。

Multiply powers

f(x)=(∛x)(x³)=x10/3

f′(x)=103x7/3,   f′(8)=12803

先把指数相加：1/3+3=10/3。

Simplify the function before differentiating; do not cancel pieces across a derivative symbol.约分发生在原函数内部。

Algebra can turn a tricky derivative into one power.08

Evaluate f′(a)

先求导函数，再代入指定输入

f(x)=√x=x1/2

f′(x)=12x−1/2=12√x

f′(16)=12·4=18

Order matters: differentiate with a variable first, then evaluate at x=16.先得到 f′(x)，再算 f′(16)。

The derivative value is the tangent slope at that input.09

Official practice 15 style

Tangent Line with the Power Rule

幂法则快速提供切线斜率

y=x³,   a=−2

point: (−2,−8)

y′=3x² ⟹ y′(−2)=12

y+8=12(x+2)

Square the negative input before multiplying: 3(−2)²=12.斜率为正 12。

Point uses the original function; slope uses the derivative.

Original function → point · derivative → slope10

Official notes example

Parallel Tangent Lines

平行切线意味着同一个 x 处导数值相等

f(x)=x⁴,   g(x)=x³

f′(x)=4x³,   g′(x)=3x²

4x³=3x² ⟹ x²(4x−3)=0

x=0 or x=34

Do not divide immediately by x²; doing so would lose the valid solution x=0.移项因式分解，保留零解。

Parallel means equal slopes, not equal function values.11

对应官方 notes 第 9 题。两条曲线在相同 x 处切线平行，不要求切点重合。

Connect back to differentiability

Domain Still Matters

套用幂法则后仍要检查导数是否在该点有定义

f(x)=x2/3

f′(x)=23x−1/3

f(0)=0, but f′(0) is undefined.

原函数在 0 有定义，导数没有。

g(x)=x⁻⁴

g′(x)=−4x⁻⁵

Neither g(0) nor g′(0) exists.

分母为 0，原函数先失去定义。

A derivative formula is meaningful only at inputs where the derivative exists.公式不能自动消除定义域限制。

Formula + domain = complete answer12

让学生比较两种“导数在 0 不存在”的原因：第一种是 cusp/vertical-style behavior，第二种原函数本身无定义。

One Complete Power-Rule Problem

改写、求导、代入、写切线

f(x)=1x⁴

Find f′(x) and the tangent line at x=2.

f′(x)=−4x⁻⁵=−4/x⁵. At x=2, the point is (2,1/16) and slope is −4/32=−1/8. Thus y−1/16=−(1/8)(x−2).原函数求点，导函数求斜率。
Rewrite the power · apply n xⁿ⁻¹ · check the domain · build the line
