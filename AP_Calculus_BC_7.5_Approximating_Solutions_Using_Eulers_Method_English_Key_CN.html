Approximating Solutions Using Euler’s Method

用欧拉法近似微分方程的解

yn+1=yn+F(xn,yn)Δx

Euler’s method walks along tangent lines to approximate a solution one step at a time.每一步用当前斜率预测下一个函数值。

Core lesson

The Euler Update

欧拉更新公式

xn+1=xn+h

yn+1=yn+F(xn,yn)h

The slope is evaluated at the old point, before the update.一定先用旧点求斜率，再更新 y。

Find the Step Size First

先算步长

h=(xend−xstart)/N

From 1 to 2

5 equal steps

Step size

h=(2−1)/5=0.2

N steps create N updates and N+1 table rows including the starting point.步数不是表格点数。

When the Slope Uses x and y

斜率同时依赖 x 与 y

y′=x+y

At every row, recompute the slope using both current coordinates.

1

record x,y

2

compute x+y

3

multiply by h

4

update y

不能只更新 x 而沿用旧斜率。

Core lesson

Euler from a Derivative Table

利用导数表做欧拉法

Suppose f(1)=2, h=0.5, and the table gives f′(1)=0.3, f′(1.5)=0.7, f′(2)=1.2.

f(2.5)≈2+0.5(0.3+0.7+1.2)=3.1

Use the left-endpoint derivative for each step.终点 x=2.5 的导数值不参与这三步。

Core lesson

Walking Backward

向左走时步长为负

h=(xend−xstart)/N<0

If f(1.5)=4 and we estimate f(1) in two equal steps, then h=−0.25.

Keep the derivative sign and the step-size sign separate.向左走由 h<0 表示，不要擅自把导数改号。

Euler for an Accumulation Function

累积函数也能使用欧拉法

H(x)=∫1x√(1+t²)dt

FTC gives H′(x)=√(1+x²) and H(1)=0. These supply the slope rule and starting value.

Once the derivative and initial value are known, the Euler table is unchanged.先用微积分基本定理得到斜率。

Core lesson

Predict Over- or Underestimation

用凹凸性判断误差方向

Concave up

Tangent lines lie below the curve locally, so forward Euler tends to underestimate.

Concave down

Tangent lines lie above the curve locally, so forward Euler tends to overestimate.

This conclusion needs consistent concavity over the steps.凹凸性若途中改变，不能直接套结论。

Step Size and Accuracy

步长与精度

Smaller |h|

more updates and usually less accumulated local error

Larger |h|

faster but follows each tangent too long

Still approximate

smaller steps do not make a finite table exact

步长越小通常越准确，但计算次数更多。

Make Two Euler Steps

完成两步欧拉法

For y′=x+y, y(0)=1, use h=0.2 to estimate y(0.4).

Answer: y₁=1+(1)(0.2)=1.2. Then slope =0.2+1.2=1.4, so y₂=1.48.第二步必须用新点 (0.2,1.2)。

Estimate an AP-Style Value

AP 风格离堂题

For y′=2x−y, y(1)=0, use three steps of size 0.1 to estimate y(1.3).

Answer: The successive estimates are 0.2, 0.4, 0.6. Thus y(1.3)≈0.6.每一步当前斜率都恰好为 2。
