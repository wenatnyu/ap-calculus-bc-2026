AP Calculus BC · Topic 8.10

Volume with Disc Method: Revolving Around Other Axes

绕其他直线旋转的圆盘法

V=π∫[distance to the shifted axis]²

For a shifted axis, the radius is still a perpendicular distance, not simply x or y. / 旋转轴平移后，半径仍是到旋转轴的垂直距离。

Core lesson

The Radius Is Not Always y

半径不一定等于 y

distance from y=f(x) to y=k is |f(x)−k|

The disc area is π[f(x)−k]² when the region touches y=k.

Core lesson

Confirm It Is a Disc

确认截面是圆盘

The region must touch the axis of rotation along the relevant boundary, so the inner radius is zero.

A positive gap creates a washer instead.

Core lesson

Axis Above the Region

旋转轴在区域上方

If y=k is above y=f(x), then R(x)=k−f(x)

Radius is positive distance; the square also removes sign, but a correct distance expression is clearer.

Horizontal-Axis Example

水平轴示例

Region between y=x and y=2, 0≤x≤2; rotate about y=2

V=π∫₀²(2−x)²dx=8π/3

Core lesson

Shifted-Axis Errors

平移轴常见错误

  • Using f(x) instead of |f(x)−k|.
  • Choosing slices parallel to the axis.
  • Using a disc when the region has a gap.
  • Forgetting to square the full distance.
FlippedMath Version #1 · Unit 812

A labeled sketch resolves all four errors.

Shifted Disc Checklist

平移圆盘法检查表

  • Sketch the region and axis.
  • Choose perpendicular slices.
  • Confirm zero inner radius.
  • Write radius as a distance.
  • Integrate πR² with matching bounds.
  • Report cubic units.

Quick Check

课堂即时检测

Answer: R=2−x, so V=π∫₀²(2−x)²dx=8π/3.
