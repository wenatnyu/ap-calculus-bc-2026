Isosceles Right Triangles

等腰直角三角形

  • If the segment is a leg: A=w²/2.
  • If the segment is the hypotenuse: A=w²/4.

Semicircles from Diameter

以直径确定半圆

r=d/2; A=½πr²=πd²/8

Most base-region problems give the diameter, not the radius.

Core lesson

Area Formula Comparison

截面积公式对照

  • square: w²
  • equilateral triangle: (√3/4)w²
  • right isosceles, leg w: w²/2
  • right isosceles, hypotenuse w: w²/4
  • semicircle, diameter w: πw²/8

Common Errors

常见错误

  • Using diameter as radius.
  • Using the wrong triangular side.
  • Integrating a length instead of an area.

Core lesson

Shape-to-Integral Checklist

从形状到积分

  • Find the base length w.
  • Read the stated shape and named side.
  • Write A in terms of w.
  • Substitute w(x) or w(y).
  • Integrate and report cubic units.
FlippedMath Version #1 · Unit 813

Quick Check

Answer: V=∫₀⁴π(√x)²/8 dx=(π/8)∫₀⁴x dx=π.
