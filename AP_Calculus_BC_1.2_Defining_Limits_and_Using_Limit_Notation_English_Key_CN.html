Build the notation

Read the Limit Notation from Left to Right

a 是输入目标；L 是输出目标

limx→af(x) = L

“The limit of f(x) as x approaches a is L.”

x → a

The input moves toward a.输入 x 靠近 a

f(x) → L

The output moves toward L.输出 f(x) 靠近 L

Important: x gets close to a; it does not need to equal a.趋近不要求取到该点。
The subscript tells where x is heading.05

手势：先指 x→a，再指 f(x)=L。要求学生完整读一遍英文，不要把 a 与 L 颠倒。

Interpretation · Say what moves where

Say the Notation as a Complete Sentence

读极限：先输入，后输出

limx→7f(x) = 10

As x approaches 7, the values of f(x) approach 10.

This statement does not say that f(7)=10.极限式不能直接告诉我们 f(7)。
Input target: 7 · Output target: 1006

纠错：原讲义的重点句更准确地应写成“A limit does not determine f(a).”极限当然描述附近的 f(x)，只是不能决定点值。

The central comparison

One Limit, Three Possibilities at the Point

同一个极限，可以对应三种点处情况

Continuous point

limx→2f(x) = 1
f(2) = 1

Hole only

limx→2f(x) = 1
f(2) is undefined

Point moved

limx→2f(x) = 1
f(2) = 3

Changing one point does not change the nearby trend.只改变一个点，不会改变附近趋势。
In every panel: lim as x approaches 2 of f(x) = 1.07

核心句：limit 看 deleted neighborhood（去心邻域）的行为；本课不用术语，只说 nearby values。逐图问 limit，再问 f(2)。

Two questions at the same x-value

Nearby Behavior and Point Value Are Different

同一个 x 值，要分开回答两个问题

The limit

limx→af(x)
  • Trace the graph near x=a.
  • Ignore a single moved or missing point.
  • Ask: “What y-value is approached?”
极限：看附近趋势
VS.

The function value

f(a)

  • Look exactly at x=a.
  • Read the y-value of the filled point.
  • If there is no filled point, the value is undefined.
函数值：看实心点
A limit does not determine f(a).08

板书：左边写 near，右边写 at。学生每做一道题先圈出它问的是 limit 还是 function value。

True or false? · Watch the words “always” and “never”

Neither Statement Is Always True

有时相等，有时不相等，也可能点值未定义

“The limit as x→a always equals f(a).”
“The limit as x→a never equals f(a).”

Both statements are false.

The limit and f(a) may be equal, different, or f(a) may be undefined.

两句都不是恒真。
A single example cannot prove “always,” but one counterexample can disprove it.11

举例：用第 7 页三幅图分别反驳 always 与 never。强调本页没有声称所有极限都存在。

A Missing Function Value Can Still Have a Limit

  1. At x=−1, find the limit and the function value.

  3. At x=3, find the limit and the function value.

x=−1: limit 2; value −2

x=3: limit −1; value undefined

AP-style interpretation · Choose the complete meaning

Interpret the Statement, Not the Point

极限式描述趋近过程，不直接给点值

limx→4f(x) = 8

Which interpretation is correct?

  • A. The function value at 4 must be 8.
  • B. The function value at 8 must be 4.
  • C. As x approaches 4, f(x) approaches 8.
  • D. As x approaches 8, f(x) approaches 4.
C. The subscript gives the input target; the number on the right gives the output target.x 靠近 4；f(x) 靠近 8。

Exit Ticket: Near the Point or At the Point?

附近趋势 vs. 点本身

  1. Find the limit as x→3.
  2. Find f(3).

    the limit as x→−2 of g(x) = 5.
