Volume with Washer Method: Revolving Around Other Axes

绕其他直线旋转的垫圈法

V=π∫([farther distance]²−[nearer distance]²)

For a shifted axis, both washer radii must be measured from that axis. / 绕平移轴旋转时，外内半径都必须从新的旋转轴量起。

Measure from the New Axis

从新的旋转轴量距离

R=farther boundary distance; r=nearer boundary distance

A=π(R²−r²)

Core lesson

Axis Above a Region

旋转轴位于区域上方

For y=k above both curves, the lower curve is farther from the axis.

R=k−ylower; r=k−yupper

FlippedMath Version #1 · Unit 804

This reverses the naive top=outer rule.

Axis Below a Region

Vertical Shifted Axis

竖直平移轴

For rotation about x=h, use horizontal slices and measure horizontal distances.

V=π∫(R(y)²−r(y)²)dy

FlippedMath Version #1 · Unit 806

Right/left does not automatically mean outer/inner; compare distance to x=h.

Core lesson

Horizontal-Axis Example

水平平移轴示例

Region between y=x and y=x² on [0,1], rotate about y=2

R=2−x², r=2−x

V=π∫₀¹[(2−x²)²−(2−x)²]dx=8π/15

FlippedMath Version #1 · Unit 807

Since the axis is above the region, the lower curve y=x² gives the outer radius.

Vertical-Axis Example

竖直平移轴示例

Region y≤x≤1 for 0≤y≤1, rotate about x=−1

R=2, r=y+1; V=π∫₀¹[4−(y+1)²]dy=5π/3

Core lesson

When the Axis Crosses the Region

旋转轴穿过区域时

A perpendicular slice may rotate into a disc rather than a washer; the outer radius is the larger reach on either side of the axis.

Split where the controlling outer boundary changes.

Radius Crossovers

半径关系变化点

Solve where competing distances are equal, then determine R and r on each interval.

piecewise V=Σπ∫(R²−r²)

Core lesson

Keep Geometry Visible

保持几何意义清晰

  • Label axis value.
  • Draw one perpendicular slice.
  • Mark both distances.
  • Name farther and nearer boundary.
  • Only then write squares.
FlippedMath Version #1 · Unit 811

This order produces more reliable algebra than memorizing sign patterns.

Core lesson

Common Shifted-Washer Errors

平移垫圈常见错误

  • Using curve coordinates instead of distances.
  • Assuming top is always outer.
  • Missing a radius crossover.
  • Using π(R−r)².
  • Failing to split when the axis crosses the region.

Shifted Washer Checklist

平移垫圈检查表

  • Sketch region and shifted axis.
  • Choose perpendicular slices.
  • Measure every radius from the axis.
  • Compare distances for R and r.
  • Split if geometry changes.
  • Integrate π(R²−r²).
