Particular Solutions using Initial Conditions and Separation of Variables

利用初始条件与变量分离法求特解

general family + initial condition
→ particular branch

An initial condition fixes the constant, chooses a branch, and anchors the solution to a valid interval.初始条件不仅求常数，还会决定正负分支与解区间。

A Clean Exponential Particular Solution

指数型特解

y′=y cos x,   y(0)=4

y=Cesin x

4=Ce⁰ ⇒ C=4

y=4esin x

初始时刻 x=0 使指数为 0，因此常数直接等于 4。

The Initial Value Chooses a Sign

初值决定正负分支

y′=6x²/y,   y(0)=−2

y²=4x³+C,   C=4

y=−2√(x³+1)

The negative branch is required because the initial value is negative.不能在最后保留 ±；特解必须经过 (0,−2)。

Branch and Domain from One Point

由一点确定分支与区间

y′=2x/y,   y(2)=1

y²=2x²−7

y=√(2x²−7),   x>√(7/2)

Choose the positive branch and the connected interval containing x=2.定义域的另一段不包含初始点，不能并入同一特解。

A Shifted Exponential Model

平移后的指数特解

y′=(1/5)(8−y),   y(0)=6

y=8+Ce−x/5

6=8+C ⇒ C=−2

y=8−2e−x/5

解从 6 上升，并渐近靠近平衡值 8。

Tangent Approximation and Exact Solution

切线近似与精确解

y′=6−2y,   y(0)=4

Tangent line

m=−2, so L(x)=4−2x.

Exact solution

y=3+e−2x.

The tangent approximation is local; the exact solution approaches the equilibrium y=3.近似只在初始点附近可靠。

Core lesson

Preserve Absolute Values Until Needed

绝对值保留到分支选择

ln|y−a|=G(x)+C

Exponentiating gives |y−a|=AeG(x). The sign may be absorbed into a nonzero constant only after both branches are understood.

Writing ln(y−a) too early can discard valid solutions with y<a.先保留绝对值，再由初值选边。

Solve and Select the Branch

求特解并选分支

Solve y′=xy² with y(0)=1.

Answer: −1/y=x²/2−1, so y=1/(1−x²/2). The maximal interval containing 0 is (−√2,√2).分母为零处不能跨越。

Complete an Initial Value Problem

完成离堂初值问题

Solve y′=ex−y with y(0)=2.

Answer: eʸdy=eˣdx, so eʸ=eˣ+C. The condition gives C=e²−1; hence y=ln(eˣ+e²−1).代回 x=0 得 y=2。
