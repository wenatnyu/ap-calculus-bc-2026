幂法则与基本导数规则

Directions: Differentiate each function. Give exact answers; no calculator.
要求：求下列函数的导数；答案保留精确形式；不使用计算器。

Formula strip: (xⁿ)′=nxⁿ⁻¹; (cf)′=cf′; (f±g)′=f′±g′; (sin x)′=cos x; (cos x)′=−sin x; (eˣ)′=eˣ; (ln x)′=1/x.

1. Find f′(x) if f(x)=x⁸.1 point
Power rule / 幂法则：
Answer: f′(x)=8x⁷. Multiply by the exponent and subtract 1 from the exponent.
2. Find y′ if y=x−3.1 point
Power rule / 幂法则：
Answer: y′=−3x−4=−3/x⁴.
3. Find g′(x) if g(x)=√x.1 point
Rewrite the root first / 先改写根式：
Answer: g(x)=x1/2, so g′(x)=(1/2)x−1/2=1/(2√x).
4. Find h′(x) if h(x)=5x⁴−3x²+7.1 point
Sum, difference, constant rules / 和、差、常数法则：
Answer: h′(x)=20x³−6x. The derivative of a constant is 0.
5. Find p′(x) if p(x)=4(x³−2x).1 point
Constant multiple rule / 常数倍法则：
Answer: p′(x)=4(3x²−2)=12x²−8.
6. If f(x)=x⁵−2x, find f′(1).1 point
Differentiate, then evaluate / 先求导，再代入：
Answer: f′(x)=5x⁴−2, so f′(1)=5−2=3.
7. Find y′ if y=sin x.1 point
Basic trigonometric derivative / 三角函数基本导数：
Answer: y′=cos x.
8. Find y′ if y=cos x.1 point
Basic trigonometric derivative / 三角函数基本导数：
Answer: y′=−sin x.
9. Find y′ if y=3eˣ−2ln x.1 point
Use both special derivatives / 使用两个特殊导数：
Answer: y′=3eˣ−2/x, for x>0.
10. Find y′ if y=x³−4cos x+ln x.1 point
Combine all applicable rules / 综合使用法则：
Answer: y′=3x²+4sin x+1/x, for x>0.
