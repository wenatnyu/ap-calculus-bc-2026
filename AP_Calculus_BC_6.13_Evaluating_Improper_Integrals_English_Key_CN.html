Evaluating Improper Integrals

计算反常积分

infinite interval or infinite discontinuity
rewrite as a limit
converge or diverge

An improper integral is defined by a limit, not by direct endpoint substitution.反常积分必须先改写为极限，再判断收敛或发散。

Two Sources of Improperness

两类反常情形

Infinite interval

At least one limit of integration is ±∞.

Infinite discontinuity

The integrand blows up at an endpoint or inside the interval.

Infinite Upper Limit

上限为无穷

∫ₐ^∞ f(x)dx

=limᵦ→∞ ∫ₐᵦ f(x)dx

The improper integral converges only if the limit is finite.

A Convergent Example

收敛例题

∫₁^∞ x⁻²dx

=limᵦ→∞[−1/x]₁ᵦ

=1

The unbounded interval can still have finite accumulated area.

The p-Integral Test

p 型积分判别

∫₁^∞ 1/xᵖ dx

converges if p>1

diverges if p≤1

The threshold is p=1.

FlippedMath Version #1 · Unit 607

This result applies to the standard interval from 1 to infinity.

Topic 6.13 · Core lesson

Interior Discontinuity

区间内部无穷间断

if f blows up at c in (a,b)

∫ₐᵇf=∫ₐᶜf+∫cᵇf

both one-sided improper integrals must converge

One divergent piece makes the entire integral diverge.

FlippedMath Version #1 · Unit 609

Both Infinite Directions

两端都是无穷

∫₋∞^∞f=∫₋∞ᶜf+∫c^∞f

each integral must converge separately

Choose any finite split point c, often 0.

Symmetry Trap

对称抵消陷阱

∫₋₁¹ 1/x² dx diverges

each side of x=0 grows to +∞

Never treat an interior vertical asymptote as ordinary signed-area cancellation.

Exponential Tail

指数尾部

∫₀^∞ e^(−2x)dx

=limᵦ→∞[−(1/2)e^(−2x)]₀ᵦ

=1/2

Exponential decay produces a finite tail.

AP-style quick check

Quick Check

课堂即时检测

Which statement is true about ∫₁^∞1/xᵖdx?

  1. Aconverges for p≥0
  2. Bconverges for p>1
  3. Cconverges for p<1
  4. Dalways diverges
Answer: B. The improper p-integral converges exactly when p>1.临界值是 p=1。

Exit Ticket

离堂检测

Evaluate and classify ∫₀^∞e^(−2x)dx.

Answer: limᵦ→∞[−(1/2)e^(−2x)]₀ᵦ=1/2, so the integral converges to 1/2.必须同时写出极限和收敛结论。
