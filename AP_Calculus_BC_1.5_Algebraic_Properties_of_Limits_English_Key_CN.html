Big idea · Replace trends with numbers

Limits Turn Algebra into Arithmetic

先读出趋势，再做普通代数

If limx→af(x)=L and limx→ag(x)=M,
then an expression built from f(x) and g(x) can usually be evaluated by combining L and M.

Read the limit data

limx→af(x)L
limx→ag(x)M

Then combine the results

limx→a[3f(x)-g(x)] = 3L-M

The value at x=a is not needed unless the problem explicitly asks for f(a) or g(a).极限看附近趋势；点值另算。

First identify L and M; then perform the algebra.03

板书只写两步：① substitute limit data ② simplify。避免学生把 f(a) 错当成 L。

Condition check · Denominator limit

The Quotient Law Has a Gate

商法则的入口条件：分母的极限不为 0

Allowed
limx→ap(x)=-4
limx→aq(x)=2
limx→ap(x)q(x)=-2

The denominator’s limit is 2, so the quotient law applies.分母极限非零，可以使用。

Blocked
limx→ap(x)=6
limx→aq(x)=0
Do not write 6 ÷ 0.

The quotient law is not applicable. This alone does not determine the original limit.不能用商法则；也不能仅凭此就断言 DNE。

Check the limit of the denominator, not only its point value.05

特别纠错：分母极限为 0 时，只能说“商法则不能直接使用”。原极限可能经约分后存在，也可能不存在；这是后续 1.6 的内容。

Input mapping · Read inside first

Map the Input Before Reading the Limit

先看括号里面趋近哪里，再查对应的极限数据

x→a→2x→2a
x→a→−x→−a
x→a→x/2→a/2

For a one-sided limit, multiplying the input by a negative number reverses the direction. 单侧极限中，负号会把左右方向翻转。

Packet example

Given

limu→−1f(u)=2
limu→1g(u)=6

limx→1[f(−x)+g(x)2]

As x→1, −x→−1. Therefore f(−x)→2 and g(x)→6, so 2+6/2=5.先把 −x 映射到 −1。
Examples: f(2x) uses the limit at 2a; g(−x) uses the limit at −a.06

让学生每次在原题上方写一行 “inside → target”。例题来自 notes Example 1。单侧方向翻转可作为口头拓展，不在本页做复杂计算。

A Function Value Is Not a Limit

函数值和极限是两类不同数据

FunctionPoint value at x = 5Limit as x → 5
ff(5)=1limx→5f(x)=6
gg(5)=2limx→5g(x)=−1
hh(5)=3limx→5h(x)=5
Inside a limit
limx→5h(x) = 5

Use the nearby trend.

Outside the limit
h(5) = 3

Use the actual point value.

Do not replace every appearance of h by the same number.先判断符号问的是“点值”还是“极限”。

Worked example · Limit laws plus point value

Mixed Expressions Need the Right Data

同一道题里可能同时出现极限数据和函数值

FunctionValueLimit
ff(5)=1limx→5f(x)=6
gg(5)=2limx→5g(x)=−1
hh(5)=3limx→5h(x)=5

limx→5[h(x)(f(x)+2g(x))]−h(5)

  1. Replace terms inside the limit by their limits.
  2. Replace h(5) by the point value.
  3. Simplify.
5[6+2(−1)]−3 = 5(4)−3 = 17
括号内用极限 5、6、−1；最后的 h(5) 用点值 3。

A reliable habit: circle every point value and underline every limit.圈出点值，划出极限，避免串列。

Same function, different symbol, different data.08

答案 17。先让学生只说替换后的数字式，不急着计算；这样能看出错误来自“取错数据”还是“代数计算”。

Composite functions · Inner trend, then outer behavior

Composition Is a Two-Step Limit

复合函数：先求内层趋近值，再读外层

1 · Inner limit

limx→ag(x)=L

Find where the inner output goes.

→

2 · Outer input

u→L

Use L as the new input target.

→

3 · Outer result

limu→Lf(u)

Or use f(L) when f is continuous at L.

If limx→2g(x)=−1 and f is continuous at −1 with f(−1)=4,
limx→2f(g(x)) = f(−1) = 4.

Compare: f(2x) has a known inner rule; f(g(x)) requires the limit of g(x) first.

Composition asks: Where does the inside go?09

可补充更一般的版本：若外层在 u→L 的极限为 M，且复合所需条件满足，则结果为 M；本页使用连续性版本，便于学生稳定操作。

Piecewise functions · Choose the branch first

Piecewise Limits Start with Direction

分段函数先按方向选分支，再比较左右结果

Left-hand limit

Use the rule valid for inputs just less than the boundary.

用边界左侧的分支。
→

Right-hand limit

Use the rule valid for inputs just greater than the boundary.

用边界右侧的分支。
→

Two-sided limit

It exists only when the two one-sided limits are equal.

左右相等，双侧才存在。

For a limit: the equality sign in x≤c or x≥c does not change the nearby trend.

For the function value: the equality sign tells you which rule supplies f(c).

Direction chooses the branch; equality chooses the point value.

Never substitute into both pieces before identifying the side.10

在边界画一条竖线。左极限只看竖线左边对应公式，右极限只看右边。强调等号只决定点值属于哪一段。

Worked example · Packet notes

One Boundary, Two Different Trends

同一边界的左右结果不同，则双侧极限不存在

f(x)= { √(11−x)x<−5 x+35−x²x≥−5

At x=−5, the left side uses the square-root branch; the right side uses the rational branch.

From the left

limx→−5−f(x)=√16=4

From the right

limx→−5+f(x)=−2−20=110
The two-sided limit is DNE. The one-sided limits are 4 and 1/10, so they are not equal. Also, f(−5)=1/10 because the second branch includes equality.双侧极限 DNE；函数值是 1/10。
Different one-sided limits → DNE.11

结果：左极限 4，右极限 1/10，双侧 DNE，点值 1/10。要求学生解释为什么点值不等于左极限并不矛盾。

Counterexample · Point value may still differ

Matching Sides Create a Limit

左右趋势相同，双侧极限存在；点值仍可不同

p(x)= { 2x+1x<3 100x=3 x+4x>3
limx→3−p(x)7
limx→3+p(x)7
limx→3p(x)7
p(3)100

The limit is 7 even though the function value is 100. The limit describes nearby behavior, not the isolated point.极限由附近趋势决定，不被单个点值改变。

Matching sides determine the limit; equality determines the point.12

这是自编反例，用来把 1.3 的“空点/实心点”语言连接到分段函数。让学生分别指出哪一行公式决定左右极限和点值。

A. limx→3[2f(x)+g(−x)]

Write the mapped target for −x before calculating.

B. limx→−3g(x)f(−x)

Check the denominator’s limit before dividing.

AP-style check · One statement must be true

AP Check: Continuity Gives One Guarantee

若 f 连续且 f(3)=7，哪一项一定成立？

If f is continuous and f(3)=7, which statement must be true?

  • Alimx→3f(3x)=9
  • Blimx→3f(2x)=14
  • Climx→3f(x)−f(3)x−3=7
  • Dlimx→3f(x²)=49
  • Elimx→3[f(x)]²=49
E. Continuity gives limx→3f(x)=f(3)=7. The power law then gives 7²=49. The other choices require information about f(6), f(9), or a derivative.连续性给出极限等于点值，再用幂法则。
Continuity connects the limit to the function value at the same input.14

正确选项 E。A、B、D 都把输入映射到别处；C 是导数型极限，题干没有给斜率信息。

g(1)−2
