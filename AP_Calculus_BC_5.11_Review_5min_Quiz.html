Directions: Write a one-variable objective function and a feasible domain. Do not solve.
要求：写出一元目标函数与可行定义域，本次不要求求最优值。

Fast check: Identify the objective, use the constraint to eliminate a variable, and restrict the model to physically possible values.

1. Two nonnegative numbers have sum 30. Write the product as a function of one variable and state its domain.3 points
Model / 建模：
Answer: P(x)=x(30−x), with 0≤x≤30.
2. A 10-by-18 sheet is turned into an open-top box by cutting x-inch squares from each corner. Write the volume model and domain.3 points
Dimensions / 尺寸：
Answer: V(x)=x(10−2x)(18−2x), with 0<x<5.
3. A rectangle has its base on the x-axis and upper corners on y=12−x². Write a one-variable area model and domain.4 points
Use symmetry / 使用对称性：
Answer: A(x)=2x(12−x²)=24x−2x³, with 0≤x≤√12. / 宽为 2x，高为 12−x²。
