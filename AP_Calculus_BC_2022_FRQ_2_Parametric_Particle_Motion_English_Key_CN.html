Part (a): Slope of a Parametric Path

（a）参数曲线的切线斜率

dy/dx = (dy/dt)/(dx/dt) = y′(t)/x′(t)

This is valid when x′(t)≠0.

不要把 dy/dx 写成 y′−x′ 或 x′/y′。

Part (b): Speed Is a Magnitude

（b）速率是速度向量的模

speed = √((x′(t))²+(y′(t))²)

Speed is never negative and has distance/time units.

速度 velocity 是向量；速率 speed 是非负标量。

Acceleration Comes from Differentiating Velocity

加速度来自速度的导数

x″(t)=t/√(1+t²)

y″(t)=2t/(2+t²)

a(t)=⟨x″(t),y″(t)⟩

分别对两个速度分量求导，并保持顺序。

Part (d): Total Distance Along the Curve

（d）沿曲线的总路程

distance = ∫₄⁶√((x′(t))²+(y′(t))²)dt

Integrate speed—not x′ alone and not the straight-line displacement.

总路程是速率积分，不是起点到终点的直线距离。

Nine-Point Map and Common Errors

  • (a) tangent slope: 1
  • (b) speed + x-acceleration + y-acceleration: 3

Quick Check

课堂快检

A particle has x′(t)=3t and y′(t)=t².

  1. Find dy/dx at t=2.
  2. Find speed at t=2.
  3. Find the acceleration vector at t=2.

分别求切线斜率、速率与加速度向量。

Answer:
  1. dy/dx=4/6=2/3.
  2. speed=√(6²+4²)=2√13.
  3. a(2)=⟨3,4⟩.

斜率是分量之比；速率是模；加速度是分量导数。

Exit ticket

Exit Ticket

离堂题

Given y(1)=4 and y′(t)=ln(1+t), write an exact expression for y(3). Then write the total-distance formula if x′(t)=2t.

先写 y 坐标，再写总路程积分；无需计算。

Answer:

y(3)=4+∫₁³ln(1+t)dt.

Total distance on [1,3]: ∫₁³√((2t)²+[ln(1+t)]²)dt.

坐标用“初值 + 分量积分”；路程用速率积分。
