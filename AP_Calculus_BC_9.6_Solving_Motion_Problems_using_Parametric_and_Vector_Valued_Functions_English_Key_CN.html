Core lesson

The Motion Dictionary

运动量之间的关系

r(t)=⟨x,y⟩,   v(t)=⟨x′,y′⟩,   a(t)=⟨x″,y″⟩

speed = ‖v(t)‖ = √((x′)²+(y′)²)

If position is in meters and time in seconds, velocity is m/s and acceleration is m/s².

Core lesson

Recover Position from Velocity

由速度恢复位置

r(t)=r(t₀)+∫t₀tv(u)du

v(t)=⟨2t,3⟩ and r(0)=⟨1,−2⟩.

r(t)=⟨1+t²,−2+3t⟩, so r(2)=⟨5,4⟩.

Core lesson

Displacement Is a Vector

位移是向量

displacement = r(b)−r(a)=∫abv(t)dt

If v=⟨3,4⟩ on [0,2], displacement is ⟨6,8⟩.

Its magnitude is 10, but the displacement itself is still the vector ⟨6,8⟩.

FlippedMath Version #1 · Unit 905

Ask students to identify the scalar and vector answers. A common error is reporting only the magnitude when displacement is requested.

Core lesson

Total Distance Integrates Speed

总路程要积分速率

distance = ∫ab‖v(t)‖dt

Displacement: integrate components.

Distance: integrate √((x′)²+(y′)²).

For v(t)=⟨1,2t⟩ on [−1,1], displacement is ⟨2,0⟩, while distance is ∫−11√(1+4t²)dt > 2.

FlippedMath Version #1 · Unit 906

Do not replace total distance by the magnitude of displacement. The strict inequality here makes the conceptual difference visible without requiring a decimal.

Core lesson

Direction of Motion

运动方向

The velocity vector is tangent to the trajectory.

T(t)=v(t)/‖v(t)‖, provided v(t)≠0

r(t)=⟨t²,t³⟩. At t=1, v=⟨2,3⟩, speed=√13, and T=⟨2/√13,3/√13⟩.

FlippedMath Version #1 · Unit 907

State the nonzero-velocity condition. At rest, the displayed unit tangent formula is undefined even if the geometric path has a tangent.

Core lesson

Speeding Up or Slowing Down

加速还是减速

d(‖v‖)/dt = (v·a)/‖v‖   when ‖v‖≠0

  • v·a>0: speeding up
  • v·a<0: slowing down
  • v·a=0: instantaneous speed derivative is 0

For v=⟨t,2⟩ and a=⟨1,0⟩, v·a=t.

FlippedMath Version #1 · Unit 908

In two dimensions, do not compare signs component by component. The dot product is the reliable test when velocity is nonzero.

Core lesson

Collision Requires the Same Time

碰撞必须发生在同一时刻

r₁(t)=r₂(t) in every component at one common t

r₁(t)=⟨t,t²⟩ and r₂(t)=⟨2−t,2t−1⟩.

The x-components give t=1; both y-components then equal 1. The particles collide at (1,1).

Crossing paths at different times is not a collision.

FlippedMath Version #1 · Unit 909

Require one common parameter value. Students should reject solutions that satisfy only one coordinate equation.

Core lesson

Return to a Point

返回某个位置

To return to the initial point, solve x(t)=x(0) and y(t)=y(0) simultaneously.

For r(t)=⟨cos t,sin t⟩, the first positive return to r(0)=⟨1,0⟩ occurs at t=2π.

Core lesson

Same Speed, Different Net Change

速率相同，净变化不同

r(t)=⟨cos t,sin t⟩, 0≤t≤π.

v=⟨−sin t,cos t⟩, so speed=1.

Distance=∫₀^π1dt=π, while displacement=r(π)−r(0)=⟨−2,0⟩.

FlippedMath Version #1 · Unit 911

This exact example cleanly separates distance π from a displacement vector. Ask which answer carries direction.

Core lesson

Read Motion Component by Component

分量解读运动

  • x′(t)>0: moving right; x′(t)<0: moving left.
  • y′(t)>0: moving up; y′(t)<0: moving down.
  • A local extremum of x or y needs a sign change in its corresponding velocity component.
  • Rest requires both velocity components to be zero.
FlippedMath Version #1 · Unit 912

Separate a zero component from zero velocity. A particle can have x′=0 and still move vertically.

Core lesson

AP Setup Checklist

AP 解题检查单

  1. Write the requested object: vector, magnitude, or scalar integral.
  2. Use the correct initial condition.
  3. For distance, integrate speed; for displacement, integrate velocity.
  4. For collision, use both coordinates at the same time.
  5. Report units and interpret the result.
FlippedMath Version #1 · Unit 913

Have students name the noun in the prompt before touching the calculator: position, displacement, distance, speed, or collision.

Quick Check

课堂即时检测

A particle has r(t)=⟨t,t²⟩ for 0≤t≤2. Find its displacement and set up its total distance.

Answer: Displacement=⟨2,4⟩. Since v=⟨1,2t⟩, distance=∫₀²√(1+4t²)dt=√17+(1/4)ln(4+√17)≈4.647.
FlippedMath Version #1 · Unit 914

Give one minute. The required distinction is the vector ⟨2,4⟩ versus the scalar speed integral; exact evaluation is enrichment.

Exit ticket

Exit Ticket

离堂检测

Do r₁(t)=⟨t,t²⟩ and r₂(t)=⟨2−t,2t−1⟩ collide for t≥0? If so, give the time and point.

Answer: Yes. The x-coordinates agree only at t=1, and then both y-coordinates equal 1. They collide at t=1 at (1,1).
FlippedMath Version #1 · Unit 915

Collect a two-equation justification. A bare intersection point without the common time does not establish a collision.
