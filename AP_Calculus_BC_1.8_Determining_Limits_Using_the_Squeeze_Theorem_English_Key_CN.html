The theorem - Three functions

The Squeeze Theorem

中间函数被两个同极限的函数夹住

If   g(x) ≤ f(x) ≤ h(x)   near x=a,
and   limx→ag(x)=L=limx→ah(x),
then   limx→af(x)=L.

Both outside limits must be the same. The order alone is not enough.上下界必须趋近同一个数；只有夹在中间还不够。

The inequalities need only hold sufficiently close to a.03

逐项点名三个条件：有上下界、下界极限存在、上界极限存在且相等。强调结论只针对中间函数。

A repeatable proof

A Three-Step Routine

每次夹逼证明都写清三步

01
State a valid bound.
Write g(x)≤f(x)≤h(x) near the target point.先写在目标点附近成立的上下界。
02
Evaluate both outside limits.
Show that both equal the same number L.分别求上下界极限，并确认两者相同。
03
Name the theorem and conclude.
Therefore, by the Squeeze Theorem, lim f(x)=L.点明“由夹逼定理”，再写中间函数的极限。

If the outside limits differ, stop: this bound gives no conclusion.若上下界极限不同，只能说这组界无法确定答案。

Bound - Evaluate - Conclude04

要求学生解题时至少出现一次完整句子 “By the Squeeze Theorem...”。如果外侧极限不同，不要硬猜中间极限。

The safest bound

Absolute Value Controls Oscillation

用绝对值统一处理双侧振荡

|sin u|≤1   and   |cos u|≤1
|A(x)q(x)|≤|A(x)|
−|A(x)|≤A(x)q(x)≤|A(x)|

When this finishes the proof

If |q(x)|≤1 and |A(x)|→0, both bounds approach 0.

Therefore A(x)q(x)→0.振荡项有界，缩放因子趋近 0，乘积被压到 0。

Absolute values avoid separate left- and right-hand cases.05

把 |sin u|≤1 与 |cos u|≤1 作为本节核心工具。绝对值形式不会因为 x 的正负而出错。

Sign check - A two-sided limit

Negative Multipliers Reverse Inequalities

乘负数时不等号必须反向

Near 0Starting boundAfter multiplying by x
x>0−1≤q(x)≤1−x≤xq(x)≤x
x<0−1≤q(x)≤1x≤xq(x)≤−x
Both sides|q(x)|≤1−|x|≤xq(x)≤|x|

Do not write −x≤xq(x)≤x across both sides of 0. It is false when x<0.双侧趋近 0 时，最稳妥的写法是使用 |x|。

Odd powers need the same sign check.06

这是本节最重要的严谨性修正。官方解答把 −x≤xq≤x 作为跨越 0 的简写；课堂上改写为 −|x|≤xq≤|x|。奇次幂同理。

Packet notes 1 - Even power

Example: A Nonnegative Multiplier

偶次幂恒非负，可以直接乘不等式

limx→0x²cos(1x²)
−1≤cos(1/x²)≤1. Since x²≥0, multiplying preserves order:
−x²≤x²cos(1x²)≤x².
Both outside limits are 0, so the limit is 0 by the Squeeze Theorem.因为 x²≥0，不等号方向不变；上下界都趋近 0。
Nonnegative factor: no reversal.07

先问 x² 的符号，再允许学生把 −1≤cos≤1 乘以 x²。强调最后必须写“by the Squeeze Theorem”。

Practice 3 - Correct two-sided bound

Example: An Odd Multiplier

奇次幂会变号，用绝对值界

limx→0x sin(1x²)
Use magnitude instead of multiplying a three-part inequality by a sign-changing number:
|x sin(1/x²)|≤|x|
−|x|≤x sin(1/x²)≤|x|.
Both bounds approach 0, so the limit is 0.x 在 0 两侧变号；绝对值写法同时覆盖左右两侧。
For x, x³, x⁵, ... use |x|, |x|³, |x|⁵, ...08

不要照抄 −x≤x sin(1/x²)≤x；当 x<0 时这个次序错误。正确双侧界是 ±|x|。

Packet notes 3 - Same outside value

Squeezing Between Two Named Functions

上下界是具体函数时，分别代入检查

g(x)=cos(π2x)+2
h(x)=x²+3

g(x)≤f(x)≤h(x) near x=0.

limx→0g(x)=3
limx→0h(x)=3
Therefore limx→0f(x)=3.两个边界都趋近 3，所以中间函数也趋近 3。
The value of f(0) is not needed.09

分别在 g 和 h 中代入 0。问学生：需要知道 f(0) 吗？不需要，极限只看附近。

Packet notes 2 - No conclusion

When the Bounds Do Not Meet

上下界极限不同，夹逼定理无法给出结论

g(x)=−x²+2x−3
h(x)=2x+1

g(x)≤f(x)≤h(x), with x→2.

limx→2g(x)=−3,   limx→2h(x)=5.
The Squeeze Theorem cannot determine the limit from these bounds.这不等于极限不存在；只能说当前信息不足。

The theorem does not apply ≠ the limit does not exist.定理不适用，不代表极限不存在。

A different argument or tighter bounds might still find the limit.10

让学生完整说：“The limit cannot be determined from these bounds.” 不接受直接写 DNE。练习 6、7、9 也属于这种情况。

A local theorem

The Bound Only Needs to Hold Nearby

不等式只需在目标点附近成立

Enough

g(x)≤f(x)≤h(x)

whenever 0<|x−a|<δ

在 a 的某个去心邻域内成立即可。
→
Not required

The inequality need not hold for every real x.

The functions need not be defined at x=a.

不要求全局成立，也不要求在 a 点有定义。

Limits describe nearby behavior, not the value at the point.极限研究的是“附近”，不是点上的函数值。

A punctured neighborhood excludes the center point.11

把 0<|x−a|<δ 读作“足够接近 a，但不等于 a”。本节不要求 epsilon-delta 证明，只要求理解局部条件。

Packet notes 4-6 - Quick check

Which Bounds Actually Work?

检查上下界是否趋近同一个数

A

−1/2≤f(x)≤x²+1/2

as x→0

Do the bounds meet?

B

−|x|³≤g(x)≤|x|³

as x→0

Do the bounds meet?

C

1−x²≤h(x)≤1+x²

as x→0

Do the bounds meet?

A: No. The bounds approach −1/2 and 1/2. B: Yes. Both approach 0, so g(x)→0. C: Yes. Both approach 1, so h(x)→1.A 只能说无法由这组界确定；B 的双侧界已用 |x|³ 修正。

B 对应 x³sin(1/x)。资料中的 −x³≤g≤x³ 只在 x>0 保持次序；双侧极限应改为 −|x|³≤g≤|x|³。A 是无法确定，不是 DNE。

Corrective Assignment 1 - Three cases

CA1 Check: Determine or Not?

先算两个边界，再决定能否夹逼

  • A.g=−(1/2)x²+x−9/2, h=cos(π(x+2))−3, x→1
  • B.g=−x²+x, h=x²−x, x→2
  • C.g=sin((π/2)(x−1))+2, h=2x²+1, x→0

In each case, g(x)≤f(x)≤h(x) near the target point.

A. Both bounds approach −4, so lim f=−4. B. The bounds approach −2 and 2, so the theorem cannot determine the limit. C. Both bounds approach 1, so lim f=1.A、C 可夹逼；B 信息不足，但不能因此写 DNE。

Guided practice - Write the absolute-value bound

Mixed Practice: Build the Bound

先写绝对值界，再写夹逼结论

A - Even power

limx→0x⁴cos(3x)

B - Odd power

limx→0x⁵sin(1x³)
A. |x⁴cos(3/x)|≤x⁴, so the limit is 0. B. |x⁵sin(1/x³)|≤|x|⁵, so −|x|⁵≤x⁵sin(1/x³)≤|x|⁵ and the limit is 0.B 的 x⁵ 会变号，因此上下界必须写成 ±|x|⁵。

The inside angle may oscillate without limit. The product can still approach 0.振荡部分本身没有极限，乘积仍可能被夹到 0。

Bound the magnitude; do not try to evaluate the oscillating factor.14

要求学生先圈出“外面的幂”，再写 |sin|≤1 或 |cos|≤1。B 对应 CA1 中奇次幂因子的同类结构。

Exit ticket - One complete explanation

Exit Ticket: State a Complete Squeeze Argument

写出完整的夹逼证明

limx→0x³cos(5x)

Write the bound, evaluate both outside limits, and name the theorem.

写出界、求两个外侧极限，并点明定理名称。
|x³cos(5/x)|≤|x|³
−|x|³≤x³cos(5/x)≤|x|³.
Since both outside limits are 0, the Squeeze Theorem gives lim x³cos(5/x)=0.cos 振荡但有界，|x|³ 把乘积压到 0。
Valid bound - Same outside limit - Squeeze conclusion
Next step: recognize when limits from different representations agree.15

收尾检查三项：绝对值界是否正确、两边是否都趋近 0、是否写出 by the Squeeze Theorem。x³ 是奇次幂，不能写 ±x³ 作为统一双侧界。
