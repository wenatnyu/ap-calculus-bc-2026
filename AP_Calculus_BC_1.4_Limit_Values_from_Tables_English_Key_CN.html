AP Calculus BC · Topic 1.4

Estimating Limit Values from Tables

Use values close to the target, compare both directions, and keep the limit separate from the function value.

用目标附近的数据比较左右趋势；极限不等同于函数值。

Limits & Continuity
Tables show numerical trends near a point.1.4

开场先问：表格里哪个数最重要？答案不是最大或最小，而是最接近目标且来自两侧的数。

Keep the questions separate

One Table Can Describe Four Quantities

左极限、右极限、双侧极限和函数值不能混为一谈

x1.91.9922.012.1
f(x)3.93.99104.014.1
limx→2−f(x)≈ 4
limx→2+f(x)≈ 4
limx→2f(x)≈ 4
f(2)10

The table suggests that the limit is 4. The function value comes from the entry at x=2.有限表格用于估计趋势；函数值看目标点本身。

Nearby values can approach 4 even when f(2) = 10.03

先分别读四个问题，再展示答案。强调表格有 x=2 这一列时也不能用它代替极限。

Existence test

The Two Sides Must Agree

左右极限不同，双侧极限不存在

x8.98.998.9999.0019.019.1
f(x)0.70.80.9992.0012.012.3
limx→9−f(x)≈1
limx→9+f(x)≈2

The table suggests different one-sided limits, so there is no single two-sided value.

Based on the data, limx→9f(x) = DNE. The value f(9) cannot be determined from this table.表中未给 f(9)，所以函数值无法判断。
Left = right is required for a two-sided limit.04

把 9 左边和右边的数据用手势分开。让学生先写两个单侧极限，再写 DNE。

A reliable reading order

Read the Table from the Inside Out

先看最接近目标的两侧数值，再向外确认趋势

x2.52.992.9993.0013.023.5
f(x)7.27.987.9988.0028.049.2

The closest pair, 7.998 and 8.002, gives the strongest estimate: 8.越接近目标，通常越有参考价值。

  1. Find the target x=a.
  2. Read the nearest value on each side.
  3. Move outward only to confirm the trend.
Distance from the target matters more than table order.05

可以故意从外侧数值 7.2 和 9.2 开始，让学生说明为什么这两个数不是最佳估计。

Calculator table

Build Values on Both Sides of the Target

自建表格时，目标两侧都要取值；目标点本身可以无定义

f(x) = (x² − 4)/(x − 2). Estimate limx→2f(x).

x1.91.991.99922.0012.012.1
f(x)3.93.993.999undefined4.0014.014.1

Good choices: a±0.1, a±0.01, a±0.001.

The table suggests limx→2f(x) ≈ 4. The undefined entry at x=2 does not stop the limit.目标点无定义，不代表极限不存在。
Do not use only values from one side.06

计算器演示可用 TABLE 或逐个输入函数值。明确禁止只选 1.9、1.99、1.999。

Packet example

Undefined at the Point Can Still Have a Limit

看附近的趋势，不把 undefined 误写成 DNE

f(x) = (x³ − 4x² − 7x + 10)/(x + 2)

x−2.1−2.001−2−1.999−1.9
f(x)22.0121.01undefined20.9920.01
limx→−2f(x)≈21The table suggests this estimate; it does not prove it.

Undefined describes f(−2). DNE would describe a failed limit.undefined 说的是函数值；DNE 说的是极限结论。

Undefined and DNE answer different questions.07

让学生完整说：“f(−2) is undefined, but the table suggests a limit of 21.”

Write Both One-Sided Limits Before DNE

不要只凭表格“跳了一下”就直接写 DNE

x8.98.998.9999.0019.019.1
f(x)0.70.80.9992.0012.012.3

limx→9−f(x)= ______

limx→9+f(x)= ______

The table suggests left: 1; right: 2. Based on the data, limx→9f(x) = DNE.先给两个单侧估计，再给双侧结论。

Continuous outer function

Apply the Outer Function After Finding the Limit

先求内层极限，再代入连续的外层函数

If

limx→af(x)=L

and g is continuous at L, then

limx→ag(f(x))=g(L)

Step 1: Read L from the table.先从表中判断内层极限。

Step 2: Evaluate g(L) with a calculator.再计算外层函数值。

Trigonometric inputs are in radians unless the problem says otherwise.

Table first, outer function second.10

板书时用箭头标出 f(x) → L → g(L)。强调 cos、exp、ln（在定义域内）都是连续外函数。

Worked example

Find the Inner Limit Before Pressing COS

先确定 f(x) 趋近 5，再计算 cos(5)

Approximate limx→2cos(f(x)).

x1.991.9992.0012.01
f(x)4.854.9995.0015.15
1. The table suggests limx→2f(x)≈5
2. cos(5) ≈ 0.284 (radians).表格先给出内层极限的估计，再按三位小数四舍五入。
The table supplies 5; continuity supplies cos(5).11

如果学生得到 0.996，通常是计算器在角度制。提醒切回弧度制。

AP-style check

Which Statement Is Supported by the Table?

表格支持的是两个单侧极限，而不是猜测 f(9)

x8.98.998.9999.0019.019.1
f(x)0.70.80.9992.0012.012.3
  • Alimx→9f(x)=1
  • Blimx→9f(x)=2
  • Cleft-hand limit = 2; right-hand limit = 1
  • Dleft-hand limit = 1; right-hand limit = 2
D. The data suggest a left-hand limit of 1 and a right-hand limit of 2, so the two-sided limit is DNE. f(9) cannot be determined.方向由 x 值决定；表中没有 f(9)。
Read the x-row before the f(x)-row.13

要求学生圈出 x<9 和 x>9 两组，再判断方向，避免把表格左右位置机械当成方向。

Exit ticket

Finish with the Limit, the Value, and a Composite

最后同时检查：左右趋势、函数值、复合函数

x4.94.99955.0015.1
f(x)2.22.00181.9991.75
  1. limx→5−f(x)
  2. limx→5+f(x)
  3. limx→5f(x)
  4. f(5)
  5. limx→5e3f(x)
1. ≈2　2. ≈2　3. ≈2　4. 8
5. e6 ≈ 403.429表格估计极限为 2；函数值 f(5)=8 是表中精确给出的。
Use the nearby trend before using the outer function.14
