Existence theorem

The Extreme Value Theorem

闭区间上的连续函数一定取得最大值和最小值

If f is continuous on the closed interval [a,b], then f attains an absolute maximum and an absolute minimum on [a,b].

Guaranteed: both values are actually reached.

Not supplied: where they occur or what the values are.

Continuous + closed and bounded interval03

EVT 的充分条件是闭区间连续；它不直接给出具体位置，需要后续方法寻找。

Definition · Domain matters

What Is a Critical Number?

先在定义域内，再检查导数

A number c in the domain of f is critical when f′(c)=0 or f′(c) does not exist.

Horizontal tangent

f′(c)=0

Corner, cusp, vertical tangent

f′(c) DNE but f(c) exists.

Hole/asymptote

Not critical if c is not in the domain.

Critical does not automatically mean extremum.05

定义中的首要短语是 c 在 f 的定义域中。导数不存在的断点若函数也不存在，就不是临界数。

A Cubic Has Two Critical Points

先求临界数，再代回原函数得到点

f(x)=⅓x³−9x+24

f′(x)=x²−9=(x−3)(x+3)

f′(x)=0 ⟹ x=−3,3

f(−3)=42

f(3)=6

Critical points:
(−3,42) and (3,6).

Critical numbers: −3 and 307

Not Every Undefined Derivative Gives a Critical Number

函数本身未定义的点不能成为临界数

g(x)=1√(4−x²),   domain (−2,2)

g′(x)=x(4−x²)3/2

g′(x)=0 ⟹ x=0

x=±2 make the derivative expression undefined, but they are not in the domain of g. Therefore, they are not critical numbers.先查原函数定义域。

Only critical number: x = 008

官方例题。分母根号要求 4-x²>0，因此定义域是 (-2,2)，端点不能列为临界数。

A Cusp Can Be Critical

导数不存在，但函数值存在

f(x)=x2/3

f′(x)=23x1/3

f(0)=0, but f′(0) does not exist.

x=0 is a critical number, and (0,0) is a local minimum.尖点也可能是极值点。

Solving only f′=0 would miss this point.

Check zero and DNE cases.09

用此例纠正“critical means horizontal tangent”的误解；临界还包括导数不存在但函数存在。

Sufficient conditions

When EVT Does Not Apply

条件失败不等于最值必然不存在

Open interval

f(x)=x on (0,1) has neither an absolute maximum nor minimum.

Discontinuity

A jump or hole can prevent an extreme value from being attained.

If EVT hypotheses fail, the theorem gives no guarantee. The function might still have extrema for other reasons.不能用定理，不代表结论一定为假。

Failure of a hypothesis removes the guarantee.13

强调逻辑：EVT 条件是充分条件。条件失败时结论可能真也可能假，需直接分析函数。

Official test prep · Question 11

Which Statement Must Be False?

递减函数在临界点处的导数

A continuous, decreasing function f on [0,10] has a critical point at (4,2). Which statement must be false?

  • A.f(10) is an absolute minimum
  • B.f(4) is neither local max nor min
  • C.f′(4) does not exist
  • D.f′(4)=0
  • E.f′(4)<0
E must be false. At a critical input in the domain, the derivative is either zero or does not exist; it cannot be a negative finite number.临界点处只能是 f′=0 或 f′ 不存在。
Official answer: E14

官方 test-prep 第 11 题。递减允许附近导数为负，但“critical point”排除了 f′(4) 为负的有限数。

Find and Classify the Candidate

导数不存在也要检查

f(x)=x2/3

Find the critical number and state whether the graph has a local extremum there.

Critical number: x=0. The function is defined at 0, while f′(0) does not exist. Since f(x)≥0=f(0), (0,0) is a local—and absolute—minimum.先证临界，再判断极值。
