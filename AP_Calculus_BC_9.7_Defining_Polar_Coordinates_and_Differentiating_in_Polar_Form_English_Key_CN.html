Polar to Cartesian

极坐标转直角坐标

x=r cosθ,   y=r sinθ,   r²=x²+y²

(r,θ)=(3,π/3)

(x,y)=(3/2,3√3/2)

One Point, Many Polar Names

同一点有多种极坐标表示

(r,θ)=(r,θ+2kπ)=(−r,θ+(2k+1)π)

(−2,π/3)=(2,4π/3), and both represent (−1,−√3).

Core lesson

Cartesian to Polar

直角坐标转极坐标

r=√(x²+y²),   tanθ=y/x

For (x,y)=(−√3,1), r=2. The point is in Quadrant II, so θ=5π/6.

Using arctan alone can give the wrong quadrant.

FlippedMath Version #1 · Unit 905

Require a quadrant check. The relation tanθ=y/x determines a family of angles, not a unique polar angle.

Core lesson

Recognize a Polar Curve

识别极坐标曲线

r=2cosθ

Multiply by r: r²=2r cosθ.

x²+y²=2x, or (x−1)²+y²=1.

The curve is a circle centered at (1,0) with radius 1.

FlippedMath Version #1 · Unit 906

Multiplying by r is useful, but remember the resulting Cartesian equation does not show tracing direction or repeated points.

Core lesson

Differentiate x and y with Respect to θ

先分别对 θ 求导

If r=f(θ), then x=r cosθ and y=r sinθ are parametric equations.

dx/dθ=r′cosθ−r sinθ

dy/dθ=r′sinθ+r cosθ

FlippedMath Version #1 · Unit 907

Both formulas use the product rule. Have students derive them rather than memorize signs in isolation.

Core lesson

Slope in Polar Form

极坐标形式的斜率

dy/dx=(r′sinθ+r cosθ)/(r′cosθ−r sinθ)

For r=2θ at θ=π/2, r′=2 and r=π.

dy/dx=2/(−π)=−2/π.

FlippedMath Version #1 · Unit 908

The denominator is dx/dθ, not r or dr/dθ. State that the quotient formula requires dx/dθ≠0.

Core lesson

Horizontal and Vertical Tangents

水平与竖直切线

Horizontal: dy/dθ=0 and dx/dθ≠0.

Vertical: dx/dθ=0 and dy/dθ≠0.

If both derivatives are zero, the simple test is inconclusive; analyze a limit or the local curve.

FlippedMath Version #1 · Unit 909

The nonzero companion condition must be in every answer. Do not label a tangent from a 0/0 quotient.

Core lesson

Worked Tangents: r=2cosθ

例题：圆的切线

For r=2cosθ:

dx/dθ=−2sin(2θ),   dy/dθ=2cos(2θ)

  • At θ=π/4, dx/dθ=−2 and dy/dθ=0: horizontal tangent.
  • At θ=0, dx/dθ=0 and dy/dθ=2: vertical tangent at (2,0).
FlippedMath Version #1 · Unit 910

Verify the actual point along with the derivative conditions. This keeps tangent classifications tied to geometry.

Core lesson

Equation of a Tangent Line

切线方程

r=1+cosθ at θ=π/2.

Point: (x,y)=(0,1). Since r′=−sinθ, dx/dθ=−1 and dy/dθ=−1, so the slope is 1.

y=x+1

FlippedMath Version #1 · Unit 911

A polar tangent-line problem needs both the Cartesian point and the slope. Check both before writing point-slope form.

Core lesson

At the Pole: Slow Down

在极点处要谨慎

For r=1−cosθ at θ=0, both r and r′ are 0, so dx/dθ=dy/dθ=0.

The slope formula gives 0/0. This does not automatically mean both a horizontal and a vertical tangent.

Use a limiting or local analysis.

FlippedMath Version #1 · Unit 912

This is a deliberate rigor checkpoint. Students should write 'inconclusive' rather than force a tangent classification.

Core lesson

Graph and Symmetry Checks

图像与对称性检查

  • Replacing θ by −θ can test x-axis symmetry.
  • Replacing θ by π−θ can test y-axis symmetry.
  • Replacing θ by θ+π can test origin symmetry.
  • These tests can prove symmetry, but failure of a test does not by itself prove no symmetry.
FlippedMath Version #1 · Unit 913

Use symmetry only as a supporting check. The key skill remains tracking signed r and the derivative denominator.

Quick Check

课堂即时检测

For r=2sinθ, classify the tangent at θ=π/4 and give the point.

Answer: r=√2 and r′=√2. Thus dx/dθ=0 and dy/dθ=2, so the tangent is vertical at (1,1), with equation x=1.
FlippedMath Version #1 · Unit 914

Require the nonzero numerator check. A denominator of zero alone is not enough when both derivatives might vanish.

Exit Ticket

Write the Cartesian point represented by (−2,π/3), then give an equivalent representation with positive radius.
