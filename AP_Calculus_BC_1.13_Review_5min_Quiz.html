5-Minute Review: Continuity on an Interval

五分钟复习：区间上的连续性

5MINUTES · 10 POINTS

Directions: Show the continuity condition or excluded values. Use interval notation when requested.
要求：写出连续性条件或需要排除的值；要求区间时使用区间记号。

Fast check: continuity at an interior point requires an existing two-sided limit equal to the function value; endpoints use the appropriate one-sided limit.

1. State the three conditions for f to be continuous at an interior point x=c.
写出函数在内点 x=c 连续的三个条件。 3 points
Conditions / 条件：
Answer: (1) f(c) is defined; (2) limx→cf(x) exists; (3) limx→cf(x)=f(c). 点值有定义、双侧极限存在、二者相等。
2. On which intervals is f(x)=(x+1)/(x²−4) continuous?
函数在哪些区间上连续？ 3 points
Excluded values and intervals / 排除值与区间：
Answer: (−∞,−2)∪(−2,2)∪(2,∞). The denominator is zero at x=−2,2; a rational function is continuous everywhere else in its domain. 分母为零的两点不在定义域内，其余各段连续。
3. Let f(x)=x² for x<1 and f(x)=2x+a for x≥1. Find a so that f is continuous at x=1.
求 a，使分段函数在 x=1 连续。 4 points
Left value = right value / 左右值相等：
Answer: a=−1. The left-hand limit is 1²=1. From the right, and at the point, f(1)=2+a. Set 2+a=1. 令左右极限与点值都等于 1，得到 a=−1。

Scoring / 评分

  • Q1: 1 point for each continuity condition.
  • Q2: 1 for excluded values; 2 for three correct intervals.
  • Q3: 1 for each one-sided value; 1 for the equation; 1 for a=−1.
  • Accept equivalent correct notation and wording.
