Integral Test for Convergence

积分判别法

Σf(n) and ∫f(x)dx share convergence behavior when f is continuous, positive, and decreasing on a tail.

The integral test connects a discrete tail to an improper integral. / 积分判别法把级数尾部与反常积分联系起来。

Core lesson

Integral Test Statement

积分判别法陈述

Let an=f(n), where f is continuous, positive, and decreasing for x≥N.

Σn=N∞an and ∫N∞f(x)dx have the same convergence behavior.

FlippedMath Version #1 · Unit 1003

All three hypotheses matter; 'eventually' is enough because finitely many terms do not affect convergence.

Core lesson

Check the Hypotheses

检查三个前提

  • Continuous on the tail.
  • Positive on the tail.
  • Decreasing on the tail.

Then match f(n)=an.

FlippedMath Version #1 · Unit 1004

Do not begin the improper integral until the tail conditions are stated.

Core lesson

Write the Improper Limit

写出反常积分极限

∫N∞f(x)dx=limb→∞∫Nbf(x)dx.

A finite limit means convergence; an infinite or nonexistent limit means divergence.

Core lesson

Convergent Example

收敛示例

Σn=1∞1/(n2+1)

f(x)=1/(x2+1) is positive and decreasing; ∫1∞f(x)dx=π/4, so the series converges.

FlippedMath Version #1 · Unit 1006

The series sum is not pi/4; only its convergence behavior matches the integral.

Divergent Example

发散示例

Σn=1∞n/(n2+1)

∫1bx/(x2+1)dx=(1/2)ln(b2+1)-(1/2)ln2→∞, so the series diverges.

Core lesson

Same Behavior, Not Same Value

收敛性相同不等于数值相同

Σf(n) ≠ ∫f(x)dx in general.

The integral test answers convergent or divergent; it does not evaluate the exact series sum.

FlippedMath Version #1 · Unit 1008

This distinction prevents students from reporting an integral value as a series sum.

Core lesson

Starting Later Is Fine

可以从较后项开始

If f becomes positive and decreasing only after x=N, start the test at N.

The omitted finite terms may change the sum but not convergence.

A Shifted Denominator

平移后的分母

Σn=1∞1/(n+2)2

∫1∞1/(x+2)2dx=1/3, so the series converges.

Core lesson

When the Test Does Not Apply

何时不能直接使用

The standard integral test does not apply directly if terms are negative or f oscillates.

Choose a different test or apply it to an appropriate positive series.

FlippedMath Version #1 · Unit 1011

A convergent improper integral is not enough without a correct discrete-continuous match.

Core lesson

Tail Bounds

尾项估计

If the integral-test hypotheses hold and Σan converges to S, define RN=S-SN. Then

∫N+1∞f(x)dx ≤ RN ≤ ∫N∞f(x)dx.

FlippedMath Version #1 · Unit 1012

Present this as a consequence for a convergent positive decreasing series; the finite sum S must exist before R_N is defined.

Core lesson

Integral-Test Workflow

积分判别流程

  1. Set f(n)=an.
  2. Verify continuous, positive, decreasing on a tail.
  3. Evaluate the improper integral.
  4. Transfer only the convergence conclusion.

Quick Check

课堂即时检测

Use the integral test on Σn=1∞n/(n2+1).

Answer: With f(x)=x/(x^2+1), the improper integral grows like (1/2)ln(x^2+1), so it diverges; the series diverges.
