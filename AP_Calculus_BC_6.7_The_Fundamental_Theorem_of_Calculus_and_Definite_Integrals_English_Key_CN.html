Topic 6.7 · Core lesson

Antiderivative

原函数

F is an antiderivative of f if F′(x)=f(x)

different antiderivatives differ by a constant

For a definite integral, the constant cancels at the endpoints.

Reverse Power Rule

反向幂函数法则

∫xⁿdx=xⁿ⁺¹/(n+1)+C, n≠−1

for definite integrals, evaluate [xⁿ⁺¹/(n+1)]ₐᵇ

The exponent −1 is the logarithm case.

FlippedMath Version #1 · Unit 605

The plus C belongs to indefinite integrals, not the final definite value.

Topic 6.7 · Core lesson

Initial-Value Problem

初值问题

f′(x)=x²−2, f(1)=−2

f(3)=f(1)+∫₁³(x²−2)dx

=−2+14/3=8/3

Change plus initial value gives the new function value.

FlippedMath Version #1 · Unit 608

This form avoids solving for a full formula when only one new value is needed.
