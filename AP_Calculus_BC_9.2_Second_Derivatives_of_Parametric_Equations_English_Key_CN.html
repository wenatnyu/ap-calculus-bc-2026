AP Calculus BC · Topic 9.2

Second Derivatives of Parametric Equations

参数方程的二阶导数与凹凸性

The first derivative gives slope. The second derivative tells how that slope changes as x changes along a parametric curve.

二阶导数必须是对 x 的变化率。

The Operator d/dx

把 d/dx 写成参数形式

Along the curve, d/dx = (1/x′(t)) d/dt, provided x′(t)≠0.

Core lesson

Second Derivative Formula

二阶导数公式

d²y/dx² = [d/dt(dy/dx)] / (dx/dt).

Differentiate the entire first-derivative expression, then divide by x′(t) again.

FlippedMath Version #1 · Unit 905

A Clean Algebra Example

代数示例

For x=t²+1, y=t³, dy/dx=3t/2 when t≠0, so d²y/dx²=(3/2)/(2t)=3/(4t).

Concavity at a Parameter Value

在给定参数处判断凹凸

If d²y/dx²>0, the curve is concave up locally; if it is negative, the curve is concave down locally.

Inflection Needs a Sign Change

拐点需要变号

A candidate occurs where d²y/dx²=0 or is undefined, but an inflection point requires an actual change in concavity on the curve.

Core lesson

AP Workflow

AP 题目作答流程

  1. Find x′ and y′.
  2. Form dy/dx.
  3. Differentiate that ratio with respect to t.
  4. Divide by x′.
  5. Evaluate and interpret the sign.

Common Traps

常见错误

  • Ignoring undefined parameter values.
  • Claiming an inflection without a sign change.

Quick check · Reveal

Reveal: Compute d²y/dx²

揭晓：计算二阶导数

Try it. For x=3t, y=t²+1, find d²y/dx².

Answer. dy/dx=2t/3; differentiating with respect to t gives 2/3, then dividing by dx/dt=3 gives 2/9.

Exit ticket

Reveal: Concavity

揭晓：判断凹凸

Try it. For x=t²+1, y=t³, state the concavity when t=−2.

Answer. d²y/dx²=3/(4t), so at t=−2 it is −3/8<0. The curve is concave down there.
