Notes example · A jump at x = 3

Different Sides Mean No Two-Sided Limit

左右极限不同 → 双侧极限不存在

Read the graph at x = 3.

limx→3−f(x)?
limx→3+f(x)?
limx→3f(x)?
Left: −1. Right: 2. Since the sides disagree, the two-sided limit is DNE. The filled point gives f(3)=2.点值不改变左右趋势。
A jump produces two different approached heights.05

先遮住实心点，分别追踪红色左支与绿色右支。最后才问 f(3)。

Notes example · One x-value, four readings

One x-Value Can Tell Four Different Stories

同一个 x：左极限、右极限、双侧极限、函数值

limx→−2−f(x)?
limx→−2+f(x)?
limx→−2f(x)?
f(−2)?
1, −2, DNE, 1. The left branch approaches 1; the right branch approaches −2. The filled point is at height 1.左右不等；函数值仍可存在。
Never merge the four questions into one.06

要求学生用方向完整表达：从左边走向 −2 时，图像趋近 y=1；从右边走向 −2 时，趋近 y=−2。

Notes example · A removable mismatch

The Limit Can Ignore the Filled Point

极限可以不等于函数值

At x=1, both branches aim at the same open circle.

limx→1f(x)?
f(1)?
The limit is 1, but the function value is −2. Nearby graph values determine the limit; the filled point determines f(1).看趋势，不看点值。
A different filled point does not move the limit.07

这是全课核心反例。可先问“图像想去哪里”，再问“函数真正取哪个值”。

Decision rule · Common graph patterns

When Does a Two-Sided Limit Exist?

判断标准只看左右趋势是否一致

What the graph does near x=aConclusionKey Chinese
One continuous branch passes through the point.limx→af(x) exists.连续通过：存在
Both sides meet at an open circle.The limit still exists.有空点也可存在
The filled point is at another height.The limit can still exist.点值可与极限不同
The two sides approach different heights.DNE跳跃：不存在
One side has no nearby graph values.The two-sided limit is DNE.缺一侧：不存在
DNE is a conclusion, not a number. It is not the same as 0.DNE ≠ 0
Match left and right before looking at f(a).08

表格读完后，让学生举例说明“函数值 undefined 但极限存在”和“函数值存在但极限 DNE”。

Guided practice · Branches and gaps

Track Each Branch Before You Answer

沿着对应分支走，不要跨过图像空档

Find these six values.

limx→−1−f(x),   limx→−1+f(x),   f(−1)
limx→0f(x),   f(2),   limx→2f(x)
3, 1, 1, 0, undefined, DNE.
At x=2, the right-hand branch approaches 1, but there are no graph values arbitrarily close from the left.函数值未定义；双侧极限 DNE。
A visible point farther away cannot replace a missing side.09

原练习 1 的其余结果：f(1)=1，左极限 at 1 为 −1，右极限 at 2 为 1。这里使用 undefined 表示 f(2)。

Guided practice · Three heights at x = −2

Separate the Limit from the Function Value

空心点读趋势，实心点读函数值

At x=−2: left limit, right limit, two-sided limit, and function value?
At x=1: limit and function value?
At −2: 1, 4, DNE, 3.
At 1: the limit is −5; the function value is undefined.
Also: limx→−3f(x)=0, f(3)=−1, f(4)=1.一个 x 位置可能出现三个不同高度。
Open circles describe approach; the filled point reports the value.10

可让学生用三种颜色分别圈出 x=−2 的左极限、右极限、函数值。

Guided practice · Compare x = 0 and x = 3

Same Graph, Two Very Different Outcomes

x=0：极限存在；x=3：左右不等

At x=0: limx→0f(x) and f(0)?
At x=3: left limit, right limit, limit, and function value?
At 0: limit 1, function value 2.
At 3: left −2, right 1, limit DNE, function value undefined.
Along the middle line, f(1)=0.同图中既可有“空点但极限存在”，也可有跳跃。
Ask exactly which quantity the notation requests.11

Reverse the process · Conditions to graph

Build the Graph One Condition at a Time

先放空心点与实心点，再连接各分支

  1. g(3)=−1
  2. limx→3g(x)=4
  3. limx→−2+g(x)=1
  4. g increases on −2<x<3.
  5. The left-hand limit at −2 is greater than the right-hand limit.
Use open circles at (−2,1) and (3,4); connect them with an increasing branch. Put a filled point at (3,−1). Make the left branch approach a height above 1.答案不唯一；逐条核验并通过垂线检验。
Open circles encode limits; filled points encode function values.12

建议按 ①函数值实心点 ②极限空心点 ③递增区间 ④左右大小关系 的顺序作图。强调答案不唯一。

Test prep · Question 6, paraphrased

A Hole Can Still Have a Limit

空心点不等于极限不存在

Which statement matches the graph?

  • AThe limits at a and b are equal.
  • Blimx→af(x)=4
  • Climx→bf(x)=4
  • Dlimx→bf(x)=5
  • EThe limit at a is DNE.
B. Both sides approach 4 at a. At b, the left side approaches 4 and the right side approaches 5, so that limit is DNE.a 是空点；b 是跳跃。
Read the curve through the hole.13

先让学生判断 a，再判断 b，不要一开始就逐项排除。正确选项 B。

Test prep · Question 7, paraphrased

Both One-Sided Limits Exist, but They Disagree

两个单侧极限都存在，双侧极限仍可不存在

At x=4, decide which statements are true.

  1. The left-hand limit exists.
  2. The right-hand limit exists.
  3. The two-sided limit exists.

Choices: I only · II only · I and II only · I and III only · all three

I and II only — choice C. The left-hand limit is 2 and the right-hand limit is 1. Each exists separately, but they are unequal, so the two-sided limit is DNE.“都存在”不等于“彼此相等”。
Existence on each side is necessary, but equality is also required.14

常见错项是“两个单侧都存在，所以双侧也存在”。要求学生补充必要条件：还必须相等。

Test prep · Question 8, paraphrased

Test Both Sides at Every Candidate

逐个检查 c = −3、0、4

For which values of c is limx→cf(x)=2?

  • A0 only
  • B0 and 4 only
  • C−3 and 0 only
  • D−3 and 4 only
  • E−3, 0, and 4
C: −3 and 0 only. A hole at −3 does not break the trend, and the semicircle approaches 2 at 0. At 4, the sides approach 2 and 3, so the limit is DNE.空点可以；跳跃不可以。
Check left, right, and equality for each candidate.15

正确选项 C。让学生先做一个三行表格，每行写左、右、结论，避免凭图像整体印象猜测。

Finish with All Four Quantities

左极限、右极限、双侧极限、函数值

limx→4−f(x)?
limx→4+f(x)?
limx→4f(x)?
f(4)?
