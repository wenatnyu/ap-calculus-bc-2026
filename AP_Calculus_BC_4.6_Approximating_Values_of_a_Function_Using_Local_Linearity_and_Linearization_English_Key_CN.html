Approximating Values Using Local Linearity

用局部线性近似函数值

Near a point of tangency, a smooth curve behaves almost like its tangent line.

f(x)≈L(x)=f(a)+f′(a)(x−a)

Why the Approximation Works

为什么切线可用于近似

f(a+Δx)≈f(a)+f′(a)Δx

Over a small interval, the derivative changes little, so the curve and tangent line stay close.在很小区间内，曲线与切线靠得很近。

“Local” matters: moving far from a usually increases error.

AP Calculus BC · 4.604

可把 Δx=x-a 写在公式旁，连接微小改变量语言。

Concavity Predicts the Error Direction

用凹向性判断高估或低估

Concave up

The graph lies above its tangent line.

L(x)<f(x)

切线低估。

Concave down

The graph lies below its tangent line.

L(x)>f(x)

切线高估。

AP Calculus BC · 4.605

让学生用图像语言说 above/below，再转成 underestimate/overestimate。

Official Example: Given Data

官方例题：已知函数值与导数值

f(4)=5, f′(4)=3; estimate f(3.8).

L(3.8)=5+3(3.8−4)=4.4

Official Example: Build the Tangent Line

官方例题：写出切线

f(1)=1,   f′(1)=−1

L(x)=1−(x−1)=2−x

f(1.1)≈L(1.1)=0.9

f″(1)=−12<0, so the estimate is an overestimate.

Exact Trigonometric Estimate

三角函数精确近似

f(x)=2cos x+1,   a=π/2

f(a)=1,   f′(a)=−2

f(1)≈1−2(1−π/2)=π−1

The function is concave down on the stated interval, so π−1 is an overestimate.

Exit Ticket

离堂检测

Use linearization at a=4 to approximate √4.1. Is the estimate high or low?

Answer: For f(x)=√x, f(4)=2 and f′(4)=1/4. Thus √4.1≈2+(1/4)(0.1)=2.025. Since √x is concave down, this is an overestimate.近似值为2.025，且为高估。
AP Calculus BC · 4.615

最后检查公式、基点差 x-a 与凹向判断。
