Fast check: Use the slope at the old point, and allow a negative step when moving left.

1. Write the Euler update for y′=F(x,y) using step size h.3 points
Update rule / 更新公式：
Answer: xn+1=xn+h and yn+1=yn+F(xn,yn)h.
2. For y′=x+y, y(0)=1, use two steps of size 0.25 to estimate y(0.5).3 points
Euler table / 欧拉表格：
Answer: y₁=1+1(0.25)=1.25; next slope is 0.25+1.25=1.5, so y₂=1.625.
3. For y′=2x, y(1)=3, use two equal steps to estimate y(0.6).4 points
Step size and updates / 步长与更新：
Answer: h=(0.6−1)/2=−0.2. Then y(0.8)≈2.6 and y(0.6)≈2.28.
