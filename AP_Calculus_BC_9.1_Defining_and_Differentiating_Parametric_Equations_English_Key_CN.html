AP Calculus BC · Topic 9.1

Defining and Differentiating Parametric Equations

参数方程：定义、轨迹与一阶导数

A point is given by (x(t), y(t)). As the parameter changes, the point traces a curve with a direction.

参数不仅决定点的位置，也保留运动方向。

Eliminate the Parameter

消去参数

Example: x=2t+1, y=t−3. Since t=(x−1)/2, the curve lies on y=(x−7)/2.

Same Curve, Different Motion

同一轨迹，不同运动

(cos t,sin t) and (cos 2t,sin 2t) trace the same unit circle, but at different speeds.

Core lesson

First Derivative Formula

参数方程的一阶导数

dy/dx = (dy/dt)/(dx/dt), provided dx/dt ≠ 0.

This is the chain rule written along the curve.

Core lesson

Horizontal and Vertical Tangents

水平切线与竖直切线

Horizontal: dy/dt=0 and dx/dt≠0.

Vertical: dx/dt=0 and dy/dt≠0.

FlippedMath Version #1 · Unit 909

If both derivatives are zero, the quotient test is inconclusive; analyze the curve rather than labeling automatically.

Repeated Points

同一点可能多次经过

Different parameter values can produce the same point. Slopes may be different, creating a self-intersection.

求某点切线时，要找出对应的所有参数值。

AP Workflow

AP 题目作答流程

  1. Identify the required parameter value.
  2. Evaluate x, y, x′, and y′.
  3. Form the correct ratio.
  4. State the requested slope, line, or condition.

Quick check · Reveal

Reveal: Slope and Tangent

揭晓：斜率与切线

Try it. For x=t²+1, y=t³−t, find the tangent line at t=2.

Answer. (x,y)=(5,6), dy/dx=(3t²−1)/(2t)=11/4, so y−6=(11/4)(x−5).

Exit ticket

Reveal: Special Tangents

揭晓：特殊切线

Try it. For x=t³−3t, y=t², classify the tangent at t=1.

Answer. dx/dt=3t²−3=0 and dy/dt=2t=2≠0; the tangent is vertical at (−2,1), so its equation is x=−2.
