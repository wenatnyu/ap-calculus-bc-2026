Core lesson

Why the Formula Has One-Half

为什么有二分之一

A sector with radius r and small angle Δθ has area approximately (1/2)r²Δθ.

ΔA≈(1/2)[r(θ)]²Δθ → A=(1/2)∫r²dθ

Angles must be in radians.

FlippedMath Version #1 · Unit 903

Connect the integral to the familiar sector formula. This gives students a reason for both the square and the one-half.

Core lesson

Bounds Must Trace the Region Once

区间必须恰好描一遍区域

  1. Find zeros r(θ)=0 and important symmetry angles.
  2. Test signed r between them.
  3. Identify when the desired loop or petal starts and ends.
  4. Check that the interval does not retrace the same region.

Do not default to [0,2π].

FlippedMath Version #1 · Unit 904

Sketch a few rays. Students should justify bounds geometrically rather than quote a memorized period without checking tracing.

Core lesson

A Circle from r=2sinθ

例题：极坐标圆

r=2sinθ traces the circle x²+(y−1)²=1 once for 0≤θ≤π.

A=(1/2)∫₀^π4sin²θdθ=π

The result matches the Cartesian area π(1)².

FlippedMath Version #1 · Unit 905

Use the Cartesian conversion as an independent check. The interval 0 to 2π would trace the circle twice.

Core lesson

One Petal of a Rose

玫瑰线的一片花瓣

For r=2cos(3θ), the petal centered on the positive x-axis is traced for −π/6≤θ≤π/6.

Apetal=(1/2)∫−π/6π/64cos²(3θ)dθ=π/3

FlippedMath Version #1 · Unit 906

Verify both endpoints are zeros and the interval traces one petal. Three petals give full area π, not six times the one-petal area.

Core lesson

Use Symmetry Only After Checking the Trace

先检查描迹，再用对称性

A multiplier is valid only when the chosen interval describes one nonoverlapping congruent piece.

Good: one verified rose petal × number of petals.

Risky: half a period × 2 without checking negative r and retracing.

FlippedMath Version #1 · Unit 907

Students often get the correct-looking multiplier for the wrong reason. Require a zero, symmetry, or tracing argument.

Core lesson

Full Cardioid Area

心形线的总面积

r=1+cosθ is traced once on 0≤θ≤2π.

A=(1/2)∫₀^{2π}(1+cosθ)²dθ

=(1/2)(2π+0+π)=3π/2

FlippedMath Version #1 · Unit 908

Expand the square correctly. The middle term integrates to zero over a full period, while cos² contributes π.

Core lesson

An Inner Loop Can Use Negative r

内环可能由负半径描出

For r=1−2cosθ, r=0 at θ=±π/3. Between those angles, r≤0 and the inner loop is traced.

Ainner=(1/2)∫−π/3π/3(1−2cosθ)²dθ=π−3√3/2

Squaring handles radial magnitude; the interval handles geometry.

FlippedMath Version #1 · Unit 909

Negative r does not create negative area. Still, students must know which loop the selected angles actually trace.

Core lesson

Area over a Specified Angular Interval

指定角区间内的面积

If a problem explicitly asks for the region swept by r=1+sinθ for 0≤θ≤π, use exactly that radial sweep:

A=(1/2)∫₀^π(1+sinθ)²dθ=3π/4+2

State which portion of the curve the interval describes.

FlippedMath Version #1 · Unit 910

This example distinguishes a requested swept region from the entire curve. Ask students to identify the upper half-plane rays.

Core lesson

Negative Radius Does Not Mean Negative Area

负半径不等于负面积

The integrand (1/2)r² is nonnegative even when r<0.

But r<0 places the point on the ray opposite θ, so signed radius changes the trace and can change valid bounds.

Algebra controls sector size; geometry controls which region is counted.
FlippedMath Version #1 · Unit 911

Do not tell students simply to ignore the sign of r. The square handles size, but the sign is essential for locating the sector.

Core lesson

Graph-First Workflow

先看图形，再写积分

  1. Find zeros and maximum radial values.
  2. Check signed r at test angles.
  3. Mark one complete tracing interval.
  4. Choose one region and confirm no overlap.
  5. Write `(1/2)∫r²dθ`, then evaluate.
FlippedMath Version #1 · Unit 912

Even with a graphing calculator, students must state why their bounds isolate the requested loop or petal.

Core lesson

Calculator and Reasonableness Checks

计算器与合理性检查

  • Use radian mode.
  • Store intersection/zero values before integrating.
  • Do not round bounds early.
  • Compare with an enclosing sector or known Cartesian area.
  • Area must be nonnegative and have square units.
FlippedMath Version #1 · Unit 913

Have students estimate size before pressing enter. A decimal result without a justified tracing interval is not a complete solution.

Exit Ticket

离堂检测

Find the area of the petal of r=2cos(2θ) centered on the positive x-axis.

Answer: The petal is traced for −π/4≤θ≤π/4. Its area is (1/2)∫−π/4π/44cos²(2θ)dθ=π/2.
