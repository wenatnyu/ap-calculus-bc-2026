The nth Term Test for Divergence

发散的第 n 项判别法

limn→∞an≠0 or DNE ⇒ Σan diverges.

The nth-term test is a fast test for divergence, never a proof of convergence. / 第 n 项判别法只能直接证明发散。

Core lesson

The Divergence Test

发散判别法

If limn→∞an≠0 or does not exist, then Σan diverges.

This test can prove divergence only.

FlippedMath Version #1 · Unit 1003

Use the full conclusion language: the series diverges because its terms do not approach zero.

Core lesson

Why It Must Be True

为什么通项必须趋零

If Sn→L, then an=Sn-Sn-1→L-L=0.

Thus a convergent series cannot keep adding a nonzero-sized term.

FlippedMath Version #1 · Unit 1004

This is a necessary-condition argument, not a complete convergence test.

Nonzero Limit Example

非零极限示例

an=(3n+1)/(5n-2) → 3/5.

Therefore Σ(3n+1)/(5n-2) diverges.

No Term Limit

通项极限不存在

an=(-1)n

The terms oscillate between -1 and 1, so the corresponding series diverges.

Core lesson

Zero Is Inconclusive

通项趋零时无法判定

lim 1/n=0, yet Σ1/n diverges.

A zero term limit passes a necessary check but does not prove convergence.

FlippedMath Version #1 · Unit 1007

A Convergent Counterexample

收敛反例

lim 1/n2=0 and Σ1/n2 converges.

The same term-limit outcome can belong to either a convergent or divergent series.

Simplify Before Taking the Limit

先化简再求极限

For rational expressions, compare leading powers of n.

For radicals, divide by the dominant power carefully and keep absolute values when needed.

Terms Versus Series

数列与级数语言

Write: 'an→2, so the series Σan diverges.'

Do not write that the series limit equals 2.

Core lesson

Use It First

优先检查通项

The nth-term test is usually the fastest first check.

If it proves divergence, stop; if the limit is zero, choose another test.

Common Logical Error

常见逻辑错误

lim an=0 ⇏ Σan converges.

The implication works only from series convergence to term limit zero.

Nth-Term Workflow

第 n 项判别流程

  1. Identify an.
  2. Compute lim an.
  3. If nonzero or DNE, state divergence.
  4. If zero, state 'inconclusive' and continue.
