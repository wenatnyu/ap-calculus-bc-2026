Core rules

Three Linear Rules

常数、常数倍、和差法则

1

Constant

d/dx [c] = 0

A fixed number does not change.常数没有变化率。

2

Constant multiple

d/dx [cu] = cu′

Keep the coefficient.系数原样保留。

3

Sum / difference

(u ± v)′ = u′ ± v′

Differentiate each term.逐项求导，符号保留。

These rules work because differentiation is a linear operation.求导对加减和常数倍具有线性。

Do not change plus or minus signs.03

用口令练习：常数变 0；系数留下；每一项分别求导。这里的 c 必须与 x 无关。

Differentiate Term by Term

先改写分式，再逐项求导

y = 2x2 − 5x + 6

= 2x2 − 5x−1 + 6

y′ = 4x + 5x−2

Sign check

(−5)(−1)=+5.

Answer: 4x+5/x2负指数求导时，两个负号相乘得到正号。

Rewrite, differentiate, then choose a clean final form.04

让学生先把 1/x 改成 x^−1。常见错误是把 −5/x 的导数写成 −5/x²；要明确符号应为正。

Roots, Powers, and Constants

根式化为分数指数；π 的幂仍是常数

y = 8√x − x63 + 2π5

y = 8x1/2 − 13x6 + 2π5

y′ = 4x−1/2 − 2x5

π is a number, so d/dx(2π5)=0.只要没有变量 x，就是常数项。

A radical is a power; π is a constant.05

先让学生判断每一项是否含 x。8√x 改写为 8x^(1/2)，x^6/3 的系数为 1/3，2π^5 直接变 0。

Derivative as slope

Horizontal Tangents

水平切线的斜率为零

f(x)=4x2+7x−13

f′(x)=8x+7

8x+7=0 ⇒ x=−78

Procedure

  1. Find the derivative.
  2. Set f′(x)=0.
  3. Solve for the input value(s).

Report x=−7/8 unless the problem asks for the whole point.题目问 x-value 时不必额外求 y。

Horizontal tangent ⇔ derivative equals zero06

强调“水平切线”是图像性质，“导数为 0”是代数条件。官方例题答案为 x=−7/8。

Official notes · Same point, perpendicular slope

A Normal Line

法线经过同一点，斜率为切线斜率的负倒数

f(x)=x3−4x2+x+3,   x=3

f(3)=−3,   f′(x)=3x2−8x+1

mtan=4,   mnormal=−1/4

y+3=−14(x−3)

Do not move the point

Both lines pass through (3,−3).

The normal slope is not merely the opposite sign. Use the negative reciprocal.不是只改符号，还要取倒数。

m(tangent) · m(normal) = −1 when both slopes are finite07

官方例题：先求点 (3,−3)，再求切线斜率 4，最后取负倒数 −1/4。建议保留点斜式。

Piecewise functions · Two gates

Differentiability at a Join

分段连接点可导需要通过两道检查

A

Continuity

f(a−) = f(a) = f(a+)

The pieces meet at the same height.左右函数值先接上。

B

Matching slope

f′−(a) = f′+(a)

The join has no corner or cusp.左右斜率还要相同。

Differentiable ⇒ continuous. The converse is false: a continuous corner is not differentiable.可导必连续；连续不一定可导。

Check values before slopes.08

固定顺序：先连续，再比较左右导数。若函数值都没有接上，直接不可导，不需要继续算斜率。

Official notes · Is it differentiable?

Check a Piecewise Join

在 x=−1 同时比较函数值与导数

f(x)= { 5x2+3x+2,   x<−1
         −7x−3,   x≥−1 }

left value = 4 = right value

left slope = 10(−1)+3 = −7

right slope = −7

Continuous

Equal one-sided derivatives

Yes, differentiable at x=−1.函数值相等，左右导数也相等。

Two checks, one conclusion09

带学生逐项代入 −1。两边函数值都是 4，左导数是 10x+3 在 −1 处等于 −7，右导数恒为 −7。

Official notes · Solve two conditions

Choose Parameters for a Smooth Join

用“连续 + 斜率相等”求两个参数

f(x)= { x2−ax+2,   x<3
         x+b,   x≥3 }

slopes: 6−a=1 ⇒ a=5

values: 11−3a=3+b ⇒ b=−7

Answer

a=5,   b=−7

Either condition may be written first, but both must appear.两个参数来自两个独立条件。

Two unknowns · Two equations10

导数条件先得到 a=5，再代入连续条件求 b=−7。也可反过来，但必须明确每个方程来自哪个条件。

Find Every Horizontal Tangent

求出全部使导数为零的 x 值

f(x)=x33+4x2+12x−13

f′(x)=x2+8x+12

Answer: x2+8x+12=(x+2)(x+6)=0, so x=−2 and x=−6.二次式有两个零点，所以有两个水平切线位置。
“Every” means keep every real solution.13

先独立完成，再显示答案。学生若只写一个 x 值，追问二次式的另一个因子。

Quick check · Multiple choice

Choose the Correct Derivative

留意分式项求导后的正负号

f(x)=3x4−2x+5

  • A.12x3−2/x2
  • B.12x3+2/x2
  • C.12x4+2/x
  • D.7x3
B. Write −2/x=−2x−1; its derivative is +2x−2.负系数乘负指数，结果为正。
Rewrite before choosing.14

要求学生先在纸上改写 −2x^−1，再看选项。答案 B。
