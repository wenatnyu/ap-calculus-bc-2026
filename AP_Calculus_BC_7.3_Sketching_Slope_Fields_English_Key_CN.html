Core lesson

What a Slope Field Shows

斜率场表示什么

Input

A point (x,y) and an equation y′=F(x,y).

Output

A short segment whose slope equals F(x,y).

A slope field displays many possible solution curves at once.一张斜率场同时容纳一族解。

Core lesson

Zero and Undefined Slopes

零斜率与未定义斜率

Zero slope

Solve F(x,y)=0; draw horizontal segments.

Undefined slope

Find where a denominator is zero; no finite segment is defined.

A nullcline is a set of points with horizontal segments; it need not itself be a solution curve.零斜率轨迹不一定就是解曲线。

Tangent Line from the Field

由斜率写切线

y′=1−xy,   (−1,−2)

m=1−(−1)(−2)=−1

y+2=−(x+1)

Local estimate: f(−0.8)≈−2.2.

斜率场的小线段就是局部切线方向。

Read Steepness, Not Length

读倾斜程度，不读线段长度

m=0

horizontal

|m| small

gently tilted

|m| large

steeply tilted

Slope −3 is steeper than slope −1/3, but both fall left to right.负号管方向，绝对值管陡峭程度。

Isoclines Organize the Picture

等斜率轨迹整理全图

y′=x−y=c

Points with the same slope c lie on

y=x−c

Each line y=x−c is an isocline. The nullcline uses c=0.同一条等斜率线上，小线段彼此平行。

Quick check · Reveal

Find One Segment

求一个方向小线段

For y′=x+y, what segment belongs at (2,−1)?

Answer: The slope is 2+(−1)=1. Draw a short rising segment through (2,−1).斜率 1：向右 1、向上 1 的方向。

Locate Every Horizontal Segment

找出全部水平小线段

For y′=y−2x, where is the slope field horizontal?

Answer: Set y−2x=0. Horizontal segments lie on y=2x.这是零斜率轨迹。
