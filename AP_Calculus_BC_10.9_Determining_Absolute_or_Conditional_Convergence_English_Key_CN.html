Determining Absolute or Conditional Convergence

判断绝对收敛或条件收敛

Absolute: Σ|an| converges. Conditional: Σan converges but Σ|an| diverges.

Classification requires a clear logical chain, not just an alternating sign. / 收敛类型需要完整的判别链条。

Core lesson

Two Types of Convergence

两种收敛类型

Σan converges absolutely if Σ|an| converges.

It converges conditionally if Σan converges but Σ|an| diverges.

FlippedMath Version #1 · Unit 1003

Write both definitions side by side; conditional convergence requires two separate conclusions.

Core lesson

Absolute Implies Ordinary

绝对收敛推出收敛

Σ|an| convergent ⇒ Σan convergent.

The reverse implication is false.

FlippedMath Version #1 · Unit 1004

This one-way implication is a theorem, not a definition.

Core lesson

Classification Workflow

收敛类型判断流程

  1. Test Σ|an|.
  2. If it converges, classify absolute.
  3. If it diverges, test the signed series.
  4. If the signed series converges, classify conditional; otherwise divergent.

Absolute Example

绝对收敛示例

Σ(-1)n/n2

The absolute series Σ1/n2 converges, so the original series converges absolutely.

Conditional Example

条件收敛示例

Σ(-1)n-1/n

AST gives convergence, while the harmonic absolute series diverges; therefore convergence is conditional.

Another Conditional Example

另一个条件收敛示例

Σ(-1)n-1/n2/3

The signed series converges by AST, but the p-series of magnitudes diverges; hence conditional convergence.

Ratio Test and Absolute Convergence

比值判别与绝对收敛

If the ratio-test limit is below 1, the series converges absolutely.

No alternating-series analysis is then necessary.

FlippedMath Version #1 · Unit 1009

The absolute value in the ratio test is why its positive conclusion is absolute.

Positive-Term Series

正项级数

If an≥0, then |an|=an.

A convergent positive-term series is automatically absolutely convergent, never conditionally convergent.

FlippedMath Version #1 · Unit 1010

Conditional convergence is a cancellation phenomenon and requires signed terms.

Divergence Is Not Conditional

发散不属于条件收敛

If Σan diverges, it is simply divergent.

Do not call it conditionally convergent merely because Σ|an| also diverges.

FlippedMath Version #1 · Unit 1011

The original series must converge before the word 'conditional' is available.

Choose Efficient Tests

高效选择判别法

  • Absolute series resembles p-series: use p or comparison.
  • Factorials/exponentials: use ratio.
  • Remaining alternating series: verify AST conditions.

Classification Checklist

分类检查表

  1. State the absolute-value series.
  2. Name its test and result.
  3. If needed, test the signed series.
  4. Use exactly one label: absolute, conditional, or divergent.
