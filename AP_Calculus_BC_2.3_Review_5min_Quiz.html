Directions: A graphing calculator is allowed. Show the secant calculation used for a table estimate; round calculator values to three decimals.
要求：可用图形计算器；表格题写出割线斜率，近似值保留三位小数。

Fast check: Use nearby inputs on opposite sides when possible. The derivative estimate carries output-units per input-unit.

1. Use the table to estimate f′(3): x: 1, 2, 4, 5; f(x): 3, 7, 15, 24.4 points
Nearest bracketing points and quotient / 两侧最近点：
Answer: Use x=2 and x=4, which bracket 3: f′(3)≈[f(4)−f(2)]/(4−2)=(15−7)/2=4.
2. Use a calculator's numerical derivative command to estimate p′(1) for p(x)=sin x. Use radians.3 points
Calculator entry + value / 输入与结果：
Answer: p′(1)≈0.540. (The exact value, learned later, is cos 1.)
3. Use p(1)≈0.841 and your estimate from Question 2 to write the tangent-line equation at x=1.3 points
Point-slope form / 点斜式：
Answer: y−0.841=0.540(x−1). Small differences caused by stored calculator precision are acceptable.
