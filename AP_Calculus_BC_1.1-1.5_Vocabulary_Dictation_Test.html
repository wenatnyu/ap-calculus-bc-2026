Topic 1.1 · Rates of Change

变化率

1. 平均变化率

average rate of change
Accepted: the average rate of change · Watch: include “average.”

2. 瞬时变化率

instantaneous rate of change
Accepted: the instantaneous rate of change · Watch: instantaneous, not “instant.”

3. 割线

secant line
Accepted: a secant line · Watch: not “tangent line.”

4. 割线斜率趋近切线斜率。

Secant slopes approach the tangent slope.
Accepted: The slopes of secant lines approach the slope of the tangent line. Watch: secant first, tangent second.

Topic 1.2 · Limit Language

极限语言

5. 极限记号

limit notation
Accepted: notation for limits · Watch: notation, not “note.”

6. 邻近值

nearby values
Accepted: values near the point · Watch: nearby does not mean “at the point.”

7. 函数值

function value
Accepted: the function value · Watch: a point value is not automatically a limit.

8. 当 x 趋近 a 时，f(x) 趋近 L。

As x approaches a, f(x) approaches L.
Accepted: As x tends to a, f(x) tends to L. Watch: “approaches” takes -es.

Topic 1.3 · Limits from Graphs

从图像读极限

9. 左极限

left-hand limit
Accepted: limit from the left · Watch: left-hand is hyphenated.

10. 右极限

right-hand limit
Accepted: limit from the right · Watch: right-hand is hyphenated.

Topic 1.3 · Limits from Graphs (continued)

从图像读极限

11. 不存在（缩写）

does not exist (DNE)
Accepted: DNE; does not exist · Watch: DNE is not “undefined.”

12. 双侧极限只有在两个单侧极限相等时才存在。

The two-sided limit exists only when the two one-sided limits are equal.
Accepted: A two-sided limit exists if the left-hand and right-hand limits are equal. Watch: both sides existing is not enough; they must agree.

Topic 1.4 · Limits from Tables

从表格读极限

13. 数值表

table of values
Accepted: table of function values · Watch: use “of,” not “for.”

14. 最接近的数值

nearest values
Accepted: closest values · Watch: values is plural here.

15. 估计 / 近似（动词，任写一个）

estimate (or approximate)
Accepted: either word earns the point · Watch: an estimate is not an exact proof.

16. 表格表明极限约为 L。

The table suggests that the limit is approximately L.
Accepted: The table suggests the limit is about L. Watch: a finite table suggests; it does not prove.

Topic 1.5 · Algebraic Properties of Limits

极限的代数性质

17. 极限定律

limit law
Accepted: law of limits; limit laws · Watch: “limit” comes first in the class term.

18. 商法则

quotient law
Accepted: quotient rule for limits · Watch: the denominator-limit condition is required.

19. 复合函数

composite function
Accepted: composition of functions · Watch: composite, not “complicated.”

20. 分母的极限必须非零。

The denominator’s limit must be nonzero.
Accepted: The limit of the denominator must not be zero. Watch: it is the limit—not necessarily the point value.
