Core lesson

When the Bound Applies

适用条件

Write the series as Σ(−1)nbn or Σ(−1)n+1bn, where bn>0.

The bound applies when bn+1≤bn eventually and bn→0. If decrease begins later, choose N so the first omitted term lies in that decreasing tail.

若只从某项起递减，截断位置也必须进入该递减区间。

FlippedMath Version #1 · Unit 1003

The theorem also works when monotonic decrease begins after finitely many terms, provided the chosen truncation is in that decreasing tail.

Core lesson

The First Omitted Term

第一个被省略的项

If S is the sum and SN uses the first N terms, then

|S−SN|≤bN+1.

The next term controls the maximum possible error.

FlippedMath Version #1 · Unit 1004

Students often use b_N. Circle N+1 before substituting.

Core lesson

The Sign of the Remainder

余项的符号

The remainder RN=S−SN has the sign of the first omitted term.

If term N+1 is positive, SN is an underestimate. If it is negative, SN is an overestimate.

看下一项的正负，就能判断估计偏高还是偏低。

Core lesson

An Interval for the Sum

无穷和所在区间

Consecutive partial sums bracket the limit:

S lies between SN and SN+1.

The interval width equals bN+1.

FlippedMath Version #1 · Unit 1006

Have students write the smaller endpoint first. This avoids assuming S_N is always the lower endpoint.

Alternating Harmonic Example

交错调和级数示例

For Σn=1∞(−1)n+1/n=ln 2,

S4=1−1/2+1/3−1/4=7/12.

|ln 2−S4|≤1/5, and 7/12≤ln 2≤47/60.

FlippedMath Version #1 · Unit 1007

The interval is intentionally broad with only four terms. The actual error is smaller than 1/5.

Core lesson

How Many Terms?

需要多少项

To guarantee an error below ε, solve

bN+1<ε.

Example: for bn=1/n² and ε=10−4, 1/(N+1)²<10−4, so the least N is 100.

FlippedMath Version #1 · Unit 1008

Strict inequality matters. N=99 gives the next term 1/10000, equal to the tolerance rather than below it.

Core lesson

Indexing the Next Term

下一项的下标

If S15 uses terms n=1 through n=15, the first omitted term has n=16.

For bn=1/(4n+1), the bound is 1/(4·16+1)=1/65.

Core lesson

Error Bound Versus Actual Error

误差界不等于实际误差

The theorem guarantees |RN|≤bN+1. It does not claim equality.

A calculator may show a much smaller actual error. The proof-level statement remains the bound.

FlippedMath Version #1 · Unit 1010

Ask students to use inequality language: at most, no greater than, or less than the requested tolerance.

Calculator Approximation

计算器近似

A Reliable Workflow

标准解题流程

  1. Identify bn.
  2. Verify decreasing terms and limit zero.
  3. Use bN+1.
  4. Compare with the required tolerance.

Core lesson

Common Errors

常见错误

  • Using bN instead of bN+1
  • Ignoring the decreasing-to-zero conditions
  • Treating the bound as the exact error
  • Solving a strict inequality as if equality were enough

Quick Check

课堂检测

For Σn=1∞(−1)n+1/(2n+1), what error is guaranteed after 10 terms?

Answer: The first omitted term has n=11, so |R10|≤1/(2·11+1)=1/23.

Exit ticket

Exit Ticket

离堂检测

Find the least N that guarantees an error below 0.01 for Σ(−1)n+1/(4n+1).

Answer: Solve 1/[4(N+1)+1]<0.01. This gives N>23.75, so the least integer is N=24.
