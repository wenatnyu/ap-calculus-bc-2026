AP Calculus BC · Topic 5.12

Exploring Behaviors of Implicit Relations

用隐式导数研究曲线行为

F(x,y)=0
dy/dx tells increase and tangent direction
d²y/dx² tells local curvature

The same derivative tests apply—even when the relation is not solved for y.即使没有写成 y=f(x)，仍可用一阶、二阶导数判断曲线行为。

Core formula

Differentiate the Relation

对关系式两边求导

F(x,y)=0

Fx+Fyy′=0

y′=−Fx/Fy

when Fy≠0

Every derivative of a y-term must include y′ by the chain rule.把 y 看成 x 的函数。

Official-notes model

Use the Sign of dy/dx

用一阶导数符号判断走向

3x³+3=ln(4y²)

9x²=2y′/y ⇒ y′=(9/2)x²y

at (−1,1/2): y′=9/4

The curve is increasing at the point because dy/dx>0.结论必须带 because 与导数符号。

Official-notes model

Differentiate a Second Time

再次隐式求导判断凹凸

x²−3=ey,   point (−2,0)

2x=eyy′ ⇒ y′=2xe−y

2=ey[(y′)²+y′′]

y′′=2e−y−(y′)²=−14

Since y′′<0, the curve is concave down at the point.二阶求导时 y′ 也随 x 变化。

Official-notes model

Classify a Horizontal Tangent

判断隐式曲线的水平切线

y³−y=x²,   point (0,1)

y′=2x/(3y²−1) ⇒ y′(0,1)=0

y′′(0,1)=1>0

The branch has a relative minimum at (0,1).一阶导数为零，二阶导数为正。

A fully algebraic example

Slope and Curvature at One Point

同一点求斜率与凹凸

x²+xy+y²=7,   point (1,2)

y′=−(2x+y)/(x+2y)=−4/5

2+2y′+2(y′)²+(x+2y)y′′=0

y′′=−42/125

At (1,2), the branch is decreasing and concave down.两个结论来自两个不同导数。

FlippedMath Version #1 · Unit 509

逐项核对二阶求导：d(xy′)/dx=y′+xy′′，d(2yy′)/dx=2[(y′)²+yy′′]。

Second derivative can simplify

Upper and Lower Branches

圆的上下半支凹凸性

x²+y²=25,   y′=−x/y

y′′=−25/y³

Upper branch: y>0 ⇒ y′′<0, concave down.

Lower branch: y<0 ⇒ y′′>0, concave up.

FlippedMath Version #1 · Unit 510

Classification warning

Zero Slope Is Only a Candidate

水平切线只是极值候选

y′ changes + to −

relative maximum

y′ changes − to +

relative minimum

no sign change

neither extremum

If y′′=0, the second derivative test is inconclusive; use a sign test.与显函数的导数判别法完全相同。

Variables may depend on time

Differentiate with Respect to t

关系式中的两个变量都随时间变化

x²−y²−5xy=25

2x dx/dt−2y dy/dt−5(x dy/dt+y dx/dt)=0

Group the dx/dt and dy/dt terms before substituting numbers.对 t 求导时 x、y 都要乘各自变化率。

Error check

Four Common Errors

隐式曲线行为题常见错误

ErrorFix
Forget y′ on a y-termApply the chain rule
Set denominator to zero and stopReturn to the original relation
Call every y′=0 point an extremumUse a sign change or second derivative
Use d²y/dx²=0 alone for inflectionVerify concavity changes

Always state the point, not only its x-coordinate.隐式关系可能在同一 x 上有多个 y。

Slope at a Point

求隐式曲线在一点的斜率

x²+xy+y²=7

Find the slope at (1,2).

  1. A−5/4
  2. B−4/5
  3. C4/5
  4. D5/4
Answer: B. From 2x+y+xy′+2yy′=0, y′=−(2x+y)/(x+2y)=−4/5.xy 求导得到 y+xy′。

Exit ticket · Tangent behavior

Find Every Special Tangent

找出全部水平与竖直切线

For x²+4y²=20, find all horizontal- and vertical-tangent points.

Answer: y′=−x/(4y). Horizontal tangents occur at x=0: (0,±√5). Vertical tangents occur at y=0: (±2√5,0).先用导数条件，再回代原椭圆方程。
