Geometry of approximation

What an Estimate Measures

用一条很短的割线逼近切线

f(a+h)−f(a−h)2h

The secant uses points on both sides of a. If the curve is smooth and the points are close, its slope is a good estimate of f′(a).

A table estimate is not guaranteed exact.表格间距越大，误差可能越大。

Nearby + opposite sides is usually the best available choice.03

图上指出两点之间的割线不是 a 点的真正切线；它只是用来逼近。可导性与数据间距都会影响估计质量。

Official practice 1

Estimate a Derivative by Calculator

在 x=−10 处估计切线斜率

f(x)=x√(2−x)

f′(−10)≈4.907

Calculator entry: numerical derivative of x√(2−x) with respect to x at −10.

The positive result says the graph is increasing locally at x=−10.正导数表示该点附近函数递增。

Keep the negative sign inside the evaluation input.

Report 4.907, not an unrounded screen dump.05

官方 solutions 给 4.907。独立核算：√12+10/(2√12)=4.907477…，三位小数为 4.907。

Units Can Change Twice

若函数本身已是速率，导数单位会再除一次时间

x (seconds)105080120150
w(x) (gal/s)950850700500150

w′(100)≈500−700120−80=−5

Units: (gal/s)/s = gal/s².原函数是每秒加仑，导数是每秒每秒。

The flow rate is decreasing by about 5 gal/s each second near 100 s.

Read the quantity, not just the numbers.08

官方 notes 第二个表格。负号说明流量在下降；−5 gal/s² 不是水量为负。

Decision rule for irregular tables

Choose the Best Pair

表格间距不规则时，按位置而非行号选点

Best case

Use the nearest values on opposite sides of a.

两侧、最近。

If a is an endpoint

Use the two nearest available values on the same side.

只能做单侧估计。

If a is listed

Usually use one nearby value on each side, not the point itself twice.

用中心差分逼近。

Do not automatically choose adjacent columns if both inputs lie on the same side and a bracketing pair exists.先看数轴位置，再看表格列。

Closeness and balance both matter.09

用数轴画出目标 a 和可用数据点，让学生说明“为什么选这两个点”。

Irregular Table Example

目标 47.5 正好位于 45 与 50 的中间

p(t) (pages/day)5120213658

p′(47.5)≈36−2150−45=3 pages/day²

The output p(t) is already pages per day, so its derivative is pages per day per day.读懂表头，单位不能漏。

The nearest pair is 45 and 50, not 13 and 70.10

When bracketing is impossible

A One-Sided Estimate

端点附近只能使用同一侧的数据

x00.20.51.0
g(x)4.004.314.825.75

g′(0)≈4.31−4.000.2−0=1.55

This is a right-hand estimate because no data are available for x<0.

It gives less evidence for a two-sided derivative.单侧数据不能独立保证两侧导数存在。

State when the estimate is one-sided.11

区分“估计右侧变化率”和“证明两侧导数”。表格通常只支持近似，不支持严格存在性证明。

Number + sign + units + instant

Interpret the Estimate

完整解释一个近似导数

v′(8)≈47.5 visitors/hour

When?

At x=8 hours.

指出时刻。

Direction?

Positive: visitor count is increasing.

正号表示增加。

How fast?

About 47.5 visitors per hour.

写数值和单位。

Near hour 8, the number of visitors is increasing at approximately 47.5 visitors per hour.

A derivative interpretation is local, not an interval average.12

官方练习 14a 的答案为 47.5 visitors/hour。避免说“从 7 到 9 一共增加 47.5 人”；那混淆了速率和变化量。

Reliability Checklist

Domain

Is the function defined near the point?

附近有定义吗？

Smoothness

Is differentiability reasonable?

有尖点或跳跃吗？

Spacing

Are the selected inputs close and balanced?

点够近、够对称吗？

Mode

Radians? Parentheses? Stored precision?

模式与输入正确吗？
